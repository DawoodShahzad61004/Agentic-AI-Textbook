from langgraph.graph import StateGraph, START, END

from state.graph_state import GraphState

from nodes.node_a import node_a
from nodes.node_b import node_b
from nodes.node_c import node_c
from nodes.node_d import node_d

from routers.routing import route_from_a


def build_graph():

    builder = StateGraph(GraphState)

    builder.add_node("A", node_a)
    builder.add_node("B", node_b)
    builder.add_node("C", node_c)
    builder.add_node("D", node_d)

    builder.add_edge(START, "A")

    builder.add_conditional_edges(
        "A",
        route_from_a,
        {
            "B": "B",
            "C": "C",
        },
    )

    builder.add_edge("B", "D")
    builder.add_edge("C", "D")

    builder.add_edge("D", END)

    return builder.compile()

Do not put something in state if it is a configuration, dependency, or constant.

the functions at edges, must they always return state or something else? Explain the concept of "return" in the edges' functions

This is one of the most important LangGraph concepts.

The short answer is:

Node functions return state updates.

Edge/router functions return routing instructions.

Those are completely different things.

1. Node Functions

Example:

def retrieve(state: GraphState) -> dict:
    docs = retriever.retrieve(state["query"])

    return {
        "retrieved_docs": docs
    }

This return value means:

Update the graph state with these values.

LangGraph internally does:

old_state = {
    "query": "ASD",
    "retrieved_docs": []
}

update = {
    "retrieved_docs": docs
}

and merges them:

new_state = {
    "query": "ASD",
    "retrieved_docs": docs
}

Notice:

return state

and

return {"retrieved_docs": docs}

are not equivalent.

Returning entire state
def retrieve(state):
    state["retrieved_docs"] = docs
    return state

works, but is discouraged.

Why?

Because now the node is rewriting everything:

{
    "query": "...",
    "answer": "...",
    "retry_count": ...
}

even though it only changed one field.

Production LangGraph code usually returns only what changed:

return {"retrieved_docs": docs}

Example:

def route_after_compression(state):
    if not state["retrieved_docs"]:
        return "retry"

    return "generate_answer"
