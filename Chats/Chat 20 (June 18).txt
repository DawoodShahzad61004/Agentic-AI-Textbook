In a langgraph workflow, how can i differentiate between a node and a service?
Thought for a couple of seconds

A node is a step in the graph.

A service is reusable helper logic that a node calls.

Think of it like this:

LangGraph workflow
   └── Node: retrieve_documents_node
          └── Service: retriever.search()

A node belongs to the workflow structure. It usually:

receives state
reads/writes values in state
represents one meaningful stage of the graph
can be connected with edges
decides what happens at that step

Example:

def retrieve_node(state):
    query = state["query"]
    docs = retriever_service.search(query)
    return {"docs": docs}

Here, retrieve_node is the node.

The service is the actual reusable logic:

class RetrieverService:
    def search(self, query):
        return vectorstore.similarity_search(query)

The service does not need to know LangGraph exists. It just performs a task.

A simple rule:

If it is part of the graph flow → node
If it performs reusable work for a node → service

Example in your RAG app:

Nodes:
- generate_subqueries_node
- retrieve_documents_node
- validate_chunks_node
- compress_context_node
- generate_answer_node
- quality_check_node

Services:
- llm_service
- retriever_service
- chunk_validator_service
- compressor_service
- logger_service
- feedback_service
- prompt_builder_service

Another way:

Node = workflow orchestration
Service = business/technical logic
State = changing data between nodes
Config = constant architecture settings

So if validate_chunks is a graph step, make it a node.

But the actual validation logic inside it can live in a service.

Best structure:

nodes/
  validate_chunks_node.py

services/
  chunk_validator_service.py

The node should stay thin. The service can be detailed.

def _normalize_source(path: str) -> str:
    return path.replace("\\", "/")


def _denormalize_source(normalized: str, original_sources: list[str]) -> str:
    for orig in original_sources:
        if _normalize_source(orig) == normalized:
            return orig
    return normalized

def execute_nac(state: GraphState) -> dict:
    accumulated_chunks = state["retrieved_docs"]
    logger.info("[COMPRESS] running NAC on %d chunk(s)", len(accumulated_chunks))

    if not accumulated_chunks:
        return {"compressed_docs": [], "nac_merge_pairs": []}

    logger.debug(f"\n{_THIN}")
    logger.debug(f"  [NAC] Neighbor-Aware Compression — scanning {len(accumulated_chunks)} chunk(s)")
    logger.debug(_THIN)

    eligible = [
        (i, c) for i, c in enumerate(accumulated_chunks)
        if isinstance(c.get("chunk_seq"), int)
    ]
    ineligible = [
        (i, c) for i, c in enumerate(accumulated_chunks)
        if not isinstance(c.get("chunk_seq"), int)
    ]

    if not eligible:
        logger.warning("  [NAC] No chunks carry chunk_seq — skipping compression.")
        logger.debug(_THIN)
        return {"compressed_docs": accumulated_chunks, "nac_merge_pairs": []}

    eligible.sort(key=lambda x: (x[1]["source"], x[1]["chunk_seq"]))
    runs: list[list[tuple[int, dict]]] = []
    current_run: list[tuple[int, dict]] = [eligible[0]]

    for orig_idx, chunk in eligible[1:]:
        prev_chunk = current_run[-1][1]
        same_source = chunk["source"] == prev_chunk["source"]
        consecutive_seq = chunk["chunk_seq"] == prev_chunk["chunk_seq"] + 1
        if same_source and consecutive_seq:
            current_run.append((orig_idx, chunk))
        else:
            runs.append(current_run)
            current_run = [(orig_idx, chunk)]
    runs.append(current_run)

    neighbor_runs = [r for r in runs if len(r) > 1]
    solo_runs = [r for r in runs if len(r) == 1]
    logger.debug(
        f"  [NAC] {len(neighbor_runs)} neighbor run(s) found | "
        f"{len(solo_runs)} singleton(s) pass through unchanged"
    )
    for run in neighbor_runs:
        seqs = [c["chunk_seq"] for _, c in run]
        logger.debug(
            f"    run: source={run[0][1]['source']}  "
            f"seq={seqs[0]}→{seqs[-1]}  ({len(run)} chunks)"
        )

    result_chunks: list[dict] = []
    nac_merge_pairs: list[dict] = []

    for run in runs:
        if len(run) == 1:
            result_chunks.append(run[0][1])
            continue

        source_chunks_for_merge = [c for _, c in run]
        candidate = _merge_similar_chunks(
            source_chunks_for_merge,
            llm,
            embedding_manager,
            output_fix_enabled=ENABLE_COMPRESSION_OUTPUT_FIX,
        )
        candidate["chunk_seq_start"] = run[0][1]["chunk_seq"]
        candidate["chunk_seq_end"] = run[-1][1]["chunk_seq"]
        candidate.pop("chunk_seq", None)
        result_chunks.append(candidate)
        nac_merge_pairs.append({"source_chunks": source_chunks_for_merge, "merged": candidate})
        logger.info(
            "  [NAC MERGE] merged %d chunks from '%s' seq %d→%d",
            len(run), run[0][1]["source"],
            run[0][1]["chunk_seq"], run[-1][1]["chunk_seq"],
        )

    result_chunks.extend(c for _, c in ineligible)

    saved = len(accumulated_chunks) - len(result_chunks)
    logger.debug(
        f"\n  [NAC] compression done: {len(accumulated_chunks)} → {len(result_chunks)} "
        f"chunk(s) ({saved} eliminated)"
    )
    logger.debug(_THIN)
    logger.info("[COMPRESS] NAC complete — %d chunk(s) remain", len(result_chunks))

    return {"compressed_docs": result_chunks, "nac_merge_pairs": nac_merge_pairs}

                if not isinstance(local_idx, int) or not sentence:
                    continue
                if local_idx < 0 or local_idx >= len(window):
                    continue
                clean_members.append({"chunk_index": local_idx, "sentence": sentence})
            if len(clean_members) < 2:
                continue
            unique_chunk_indices = {m["chunk_index"] for m in clean_members}
            if len(unique_chunk_indices) < 2:
                logger.debug(
                    f"  [DC] group dropped — all {len(clean_members)} member(s) "
                    f"are from chunk_index={next(iter(unique_chunk_indices))} "
                    f"(intra-chunk repetition, not cross-chunk redundancy)"
                )
                continue
            valid_groups.append(clean_members)

        if not valid_groups:
            logger.warning("  [DC] no structurally valid groups after normalization — skipping window")
            continue

        dc_groups_per_window.append({"window_chunks": list(window), "groups": valid_groups})

        confirmed_groups = [{"members": members} for members in valid_groups]

        flags_by_local: dict[int, list[str]] = {}
        for entry in confirmed_groups:
            members = entry["members"]
            keeper_idx = min(m["chunk_index"] for m in members)
            for m in members:
                if m["chunk_index"] != keeper_idx:
                    flags_by_local.setdefault(m["chunk_index"], []).append(m["sentence"])

        for local_idx, sentences_to_remove in flags_by_local.items():
            global_idx = window_start + local_idx
            original_chunk = result[global_idx]
            original_content = (original_chunk.get("content") or "").strip()

            cleaned_content = original_content
            for sentence in sentences_to_remove:
                if sentence in cleaned_content:
                    cleaned_content = cleaned_content.replace(sentence, "").strip()
                else:
                    norm_sentence = " ".join(sentence.split())
                    norm_content = " ".join(cleaned_content.split())
                    if norm_sentence in norm_content:
                        cleaned_content = norm_content.replace(norm_sentence, "").strip()

            if cleaned_content == original_content:
                logger.warning(f"  [DC] chunk {global_idx}: no change after removal attempt — skipping")
                continue
            if len(cleaned_content.strip()) < 50:
                logger.warning(
                    f"  [DC] chunk {global_idx}: cleaned content too short — skipping "
                    f"(would remove too much)"
                )
                continue

            removed_count = len(sentences_to_remove)
            logger.debug(
                f"\n  [DC] chunk {global_idx}: removing {removed_count} confirmed-redundant sentence(s)"
            )
            logger.debug(
                f"    before ({len(original_content)} chars): {original_content[:150]}…"
            )
            logger.debug(
                f"    after  ({len(cleaned_content)} chars): {cleaned_content[:150]}…"
            )
            result[global_idx] = {**original_chunk, "content": cleaned_content}
            total_sentences_removed += removed_count
            logger.debug(f"  [DC] chunk {global_idx}: INSTALLED cleaned version ✓")

    logger.debug(
        f"\n  [DC] done — {total_sentences_removed} redundant passage(s) removed "
        f"across {len(result)} chunk(s)"
    )
    logger.debug(_THIN)
    logger.info("[COMPRESS] DC complete — %d chunk(s) remain", len(result))

    return {"compressed_docs": result, "dc_groups_per_window": dc_groups_per_window}

                break

                logger.warning(f"  [LBC] chunk {idx}: empty response on attempt {attempt}, retrying…")
                continue

            else:

            if _ok and isinstance(candidate, dict) and "compressed" in candidate:

                f"{min_retention_ratio} — keeping original (over-compression guard)"

            total_chars_after += len(original_content)
            skipped += 1
            continue

        if len(compressed_text) > len(original_content):

                f"  [LBC] chunk {idx}: 'compressed' output expanded "
                f"({len(original_content)} → {len(compressed_text)} chars) "
                f"— keeping original (over-expansion guard)"
            )
            result.append(chunk)
            total_chars_after += len(original_content)
            skipped += 1
            continue

            result.append(chunk)
            total_chars_after += len(original_content)
            skipped += 1
            continue

        compressed_chunk_dict = {**chunk, "content": compressed_text}
        lbc_validation_pairs.append({"original": chunk, "compressed": compressed_chunk_dict})
        result.append(compressed_chunk_dict)
        total_chars_after += len(compressed_text)
        accepted += 1
        logger.info(
            "  [LBC] chunk %d: compressed (%d → %d chars, −%d chars)",
            idx, len(original_content), len(compressed_text),
            len(original_content) - len(compressed_text),
        )

    saved_chars = total_chars_before - total_chars_after
    pct = (saved_chars / max(total_chars_before, 1)) * 100
    logger.debug(
        f"\n  [LBC] done — {len(chunks)} → {len(result)} chunk(s) "
        f"({irrelevant_dropped} dropped as irrelevant, "
        f"{accepted} compressed, {skipped} kept as-is)"
    )
    logger.debug(
        f"  [LBC] chars: {total_chars_before:,} → {total_chars_after:,} "
        f"(-{saved_chars:,} = {pct:.1f}% reduction)"
    )
    logger.debug(_THIN)
    logger.info("[COMPRESS] LBC complete — %d chunk(s) remain", len(result))

    return {"compressed_docs": result, "lbc_validation_pairs": lbc_validation_pairs}

def _build_system_prompt(

    prior_thumbdowns: list[dict] | None = None,

    parts = [_ROLE_AND_RULES]

    if blocked_variants:

        parts.append(
            "BLOCKED QUERY VARIANTS — These exact phrasings retrieved 0 useful chunks"
            " the last time this question was asked. Do NOT reuse them under any"

            f"\n{lines}"

            " was asked before and the user explicitly marked the answer as bad. Below is"
            " what went wrong last time, including the exact query reformulations that were"
            " tried and the chunks they retrieved.\n"
            "  1. AVOID re-using the same query reformulations — they led to a bad answer.\n"
            "  2. AVOID grounding your answer in the same chunks unless you can clearly"
            " interpret them differently.\n"
            "  3. Try genuinely different angles, vocabulary, and sub-topics.\n"
        )

            td_history_block += f"\n--- Prior failure #{i} ---\n"

            bad_ans = td.get("bad_answer", "")

                    learned_qa_chunks = v.get("learned_qa_chunks", []) or []
                    for track_name, chunks in (
                        ("learned_qa", learned_qa_chunks),

def _approx_token_count(chunks: list[dict]) -> int:
    total_chars = 0
    for c in chunks:
        content = c.get("content", "") or ""
        total_chars += len(content)
    return total_chars // 4

            result = "No relevant documents found for this query."
            logger.debug(f"\n{_SEP}")
            logger.debug(f"  TOOL RESULT — retrieve_documents")
            logger.debug(_SEP)
            logger.debug(f"  {result}")
            logger.debug(_SEP)
            return result

        def _format_track(title: str, chunks: list[dict]) -> str:
            if not chunks:
                return f"[{title}]\nNo relevant chunks found."
            content = "\n\n".join(
                f"[Source: {d['metadata'].get('source', '?')}, "
                f"score: {d['similarity_score']:.3f}]\n{d['content']}"
                for d in chunks
            )
            return f"[{title}]\n{content}"

        result = "\n\n".join([
            _format_track("LEARNED QA RESULTS - HIGH PRIORITY", learned_qa),
            _format_track("DOCUMENT RESULTS - SECONDARY", documents),

        logger.debug(f"\n{_SEP}")
        logger.debug(f"  RETRIEVED (unfiltered) — retrieve_documents(\"{query}\")")
        logger.debug(
            f"  documents={len(documents)} | learned_qa={len(learned_qa)} | "
            f"{len(result)} chars total - pending separate relevance checks"

        logger.debug(_SEP)
        logger.debug(result)
        logger.debug(_SEP)

        logger.debug(f"  learned QA chunks : {len(learned_qa_chunks)}")
        logger.debug(f"  query             : \"{query[:120]}\"")

def make_check_answer_quality(judge_llm):
    # Lazy imports — same sys.path requirement as make_tools.
    from llm_caller import llm_invoke
    from config import MIN_ANSWER_LENGTH
    from prompts import GROUNDING_PROMPT, GROUNDING_PROMPT_WITH_THUMBDOWN

    def check_answer_quality(
        answer: str,
        context: str,
        query: str,
        prior_thumbdowns: list[dict] | None = None,
    ) -> str:
        if not context or len(context.strip()) < 50:
            return "INSUFFICIENT — no supporting context was retrieved."

        if len(answer.strip()) < MIN_ANSWER_LENGTH:
            return (
                f"INSUFFICIENT — answer is too brief ({len(answer.strip())} chars, "
                f"minimum {MIN_ANSWER_LENGTH}). Expand using the retrieved chunks."
            )

        if judge_llm is None:
            return "OK"

        thumbdown_feedback = _extract_thumbdown_feedback(prior_thumbdowns)

        if thumbdown_feedback:
            grounding_prompt = GROUNDING_PROMPT_WITH_THUMBDOWN.format(
                answer=answer,
                context=context[:3000],
                query=query or "(not provided)",
                thumbdown_feedback=thumbdown_feedback,
            )
            caller_tag = "CAQ-JUDGE-TD"
        else:
            grounding_prompt = GROUNDING_PROMPT.format(
                answer=answer, context=context[:3000], query=query or "(not provided)"
            )
            caller_tag = "CAQ-JUDGE"

        result = llm_invoke(
            judge_llm,
            [{"role": "user", "content": grounding_prompt}],
            caller_tag=caller_tag,
        )

        if not result.ok:
            logger.warning(f"  [{caller_tag}] LLM call failed ({result.error_kind}), defaulting to OK")
            return "OK"

        verdict = result.content.strip()
        logger.debug(f"  [{caller_tag}] verdict: {verdict[:120]}")

        if verdict.upper().startswith("OK"):
            return "OK"
        else:
            reason = verdict if verdict else (
                "answer does not adequately address the query using the retrieved chunks"
            )
            return f"INSUFFICIENT — {reason.removeprefix('INSUFFICIENT — ').removeprefix('INSUFFICIENT: ')}"

    return check_answer_quality

import logging
from state import GraphState
from app_workflow.services.llm_setup import judge_llm

from app_workflow.services.validators import validate_retrieval

def execute_validate_retrieval(state: GraphState) -> dict:
    """Per-variant node: judge retrieved chunks for relevance and filter out irrelevant ones.

    Runs in parallel for each query variant (same super-step as retrieve).
    Writes to validated_chunks via operator.add reducer so all variants accumulate.
    """
    chunks = state.get("retrieved_docs") or []
    query = state.get("query") or state.get("user_input") or ""

    if not chunks:
        logger.debug("[VALIDATE_RETRIEVAL] no chunks — skipping, query: %r", query[:60])
        return {"validated_chunks": []}

    if not ENABLE_RETRIEVAL_VALIDATION:
        logger.debug(
            "[VALIDATE_RETRIEVAL] disabled — passing through %d chunk(s)", len(chunks)
        )
        return {"validated_chunks": list(chunks)}

    result = validate_retrieval(query, chunks, judge_llm)
    verdict = result["verdict"]

    irrelevant_idx: set[int] = set()
    if verdict != "UNKNOWN":
        for pc in result.get("per_chunk", []):
            if pc.get("relevant") is False and isinstance(pc.get("index"), int):
                irrelevant_idx.add(pc["index"])

    kept = [c for i, c in enumerate(chunks) if i not in irrelevant_idx]
    logger.debug(
        "[VALIDATE_RETRIEVAL] verdict=%s | kept %d/%d chunk(s) | query: %r",
        verdict, len(kept), len(chunks), query[:60],
    )
    return {"validated_chunks": kept}

import logging
from state import GraphState
from app_workflow.services.llm_setup import llm, judge_llm
from app_workflow.services.services import embedding_manager
from app_workflow.services.validators import validate_merge
from app_workflow.services.config import (
    ENABLE_RETRIEVAL_DEDUP_MERGE,
    ENABLE_RETRIEVAL_DEDUP_MERGE_VALIDATION,
    ENABLE_COMPRESSION_OUTPUT_FIX,
    MERGE_SIMILARITY_THRESHOLD,
)
from app_workflow.nodes.nac import _merge_similar_chunks

logger = logging.getLogger(__name__)


def execute_dedup_merge(state: GraphState) -> dict:
    """Serial node: dedup and merge near-duplicate chunks across all query variants.

    Runs after all parallel validate_retrieval branches complete. Reads the fully
    accumulated validated_chunks, groups near-duplicates by cosine similarity
    (>= MERGE_SIMILARITY_THRESHOLD), merges each group via LLM, and writes the
    result to dedup_merged_chunks for NAC to consume.

    Note: In LangGraph's super-step model this node runs once per completed
    validate_retrieval branch (N times for N variants), but each invocation reads
    the same complete validated_chunks state, so the final write is correct.
    """
    validated_chunks: list[dict] = state.get("validated_chunks") or []

    if not validated_chunks:
        logger.debug("[DEDUP_MERGE] no validated chunks — skipping")
        return {"dedup_merged_chunks": [], "dedup_merge_pairs": []}

    if not ENABLE_RETRIEVAL_DEDUP_MERGE:
        logger.debug(
            "[DEDUP_MERGE] disabled — passing through %d chunk(s)", len(validated_chunks)
        )
        return {"dedup_merged_chunks": list(validated_chunks), "dedup_merge_pairs": []}

    # Generate embeddings for pairwise similarity comparison
    chunks_with_emb: list[dict] = []
    for c in validated_chunks:
        content = (c.get("content") or "").strip()
        if not content:
            continue
        emb = embedding_manager.generate_embedding(content)
        chunks_with_emb.append({**c, "embedding": emb})

    # Find near-duplicate groups via pairwise cosine similarity
    claimed: set[int] = set()
    merge_groups: list[list[int]] = []
    for i in range(len(chunks_with_emb)):
        if i in claimed:
            continue
        group = [i]
        for j in range(i + 1, len(chunks_with_emb)):
            if j in claimed:
                continue
            sim = embedding_manager.cosine_similarity(
                chunks_with_emb[i]["embedding"],
                chunks_with_emb[j]["embedding"],
            )
            if sim >= MERGE_SIMILARITY_THRESHOLD:
                group.append(j)
                claimed.add(j)
        if len(group) > 1:
            claimed.add(i)
            merge_groups.append(group)

    logger.debug(
        "[DEDUP_MERGE] %d chunk(s) → %d merge group(s) (threshold=%.2f)",
        len(chunks_with_emb), len(merge_groups), MERGE_SIMILARITY_THRESHOLD,
    )

    dedup_merge_pairs: list[dict] = []
    indices_to_drop: set[int] = set()

    for group in merge_groups:
        keeper_idx = group[0]
        source_chunks = [chunks_with_emb[i] for i in group]
        merged = _merge_similar_chunks(
            source_chunks,
            llm,
            embedding_manager,
            output_fix_enabled=ENABLE_COMPRESSION_OUTPUT_FIX,
        )
        chunks_with_emb[keeper_idx] = merged
        dedup_merge_pairs.append({"source_chunks": source_chunks, "merged": merged})
        indices_to_drop.update(group[1:])
        logger.info(
            "[DEDUP_MERGE] merged %d near-duplicate chunk(s) from: %s",
            len(group),
            [chunks_with_emb[i].get("source", "?") for i in group],
        )

    # Build clean output chunks (strip internal embedding vectors)
    result_chunks: list[dict] = []
    for i, c in enumerate(chunks_with_emb):
        if i in indices_to_drop:
            continue
        clean: dict = {"content": c["content"], "source": c["source"]}
        if isinstance(c.get("chunk_seq"), int):
            clean["chunk_seq"] = c["chunk_seq"]
        result_chunks.append(clean)

    saved = len(chunks_with_emb) - len(result_chunks)
    logger.info(
        "[DEDUP_MERGE] %d → %d chunk(s) (%d merged/eliminated)",
        len(chunks_with_emb), len(result_chunks), saved,
    )
    return {"dedup_merged_chunks": result_chunks, "dedup_merge_pairs": dedup_merge_pairs}


def validate_dedup_merge(state: GraphState) -> dict:
    """Post-hoc faithfulness check for each dedup merge pair (logging only, no retry)."""
    pairs: list[dict] = state.get("dedup_merge_pairs") or []
    if not pairs:
        logger.debug("[VALIDATE_DEDUP_MERGE] no merge pairs to validate")
        return {}
    for i, pair in enumerate(pairs):
        check = validate_merge(pair["source_chunks"], pair["merged"], judge_llm)
        logger.info(
            "[VALIDATE_DEDUP_MERGE] pair %d: verdict=%s  fabricated=%d  dropped=%d",
            i,
            check["verdict"],
            len(check.get("fabricated_claims", [])),
            len(check.get("dropped_claims", [])),
        )
    return {}

import logging
from state import GraphState
from app_workflow.services.services import retriever
from app_workflow.config import MIN_SIMILARITY, RETRIEVAL_TOP_K, RETRIEVAL_TOP_L

logger = logging.getLogger(__name__)


def _flatten_chunks(chunks: list[dict]) -> list[dict]:
    flat = []
    for d in chunks:
        meta = d.get("metadata") or {}
        item: dict = {
            "content": d.get("content", ""),
            "source": meta.get("source", "?"),
            "similarity_score": d.get("similarity_score", 0.0),
        }
        if isinstance(meta.get("chunk_seq"), int):
            item["chunk_seq"] = meta["chunk_seq"]
        flat.append(item)
    return flat


def retrieve(state: GraphState) -> dict:
    """Query both collections with a single embedding for the current variant.

    Called in parallel for each query variant via LangGraph Send.  The two
    resulting lists are accumulated into the main state via Annotated reducers
    (operator.add), so all variant results are gathered before validation runs.
    """
    query = state["query"]

    results = retriever.retrieve_separate(
        query,
        top_k=RETRIEVAL_TOP_K,
        top_l=RETRIEVAL_TOP_L,
        score_threshold=MIN_SIMILARITY,
    )

    doc_chunks = _flatten_chunks(results["documents"])
    qa_chunks = _flatten_chunks(results["learned_qa"])

    logger.debug(
        "[RETRIEVE] query=%r  docs=%d  learned_qa=%d",
        query[:60], len(doc_chunks), len(qa_chunks),
    )

    return {
        "retrieved_document_chunks": doc_chunks,
        "retrieved_learned_qa_chunks": qa_chunks,
    }

import logging
from state import GraphState
from app_workflow.services.llm_setup import judge_llm
from app_workflow.config import ENABLE_RETRIEVAL_VALIDATION
from app_workflow.services.validators import validate_retrieval

logger = logging.getLogger(__name__)


def _validate_track(track_name: str, chunks: list[dict], query: str) -> list[dict]:
    if not chunks:
        logger.debug("[VALIDATE_%s] no chunks — skipping", track_name.upper())
        return []

    if not ENABLE_RETRIEVAL_VALIDATION:
        logger.debug(
            "[VALIDATE_%s] disabled — passing through %d chunk(s)",
            track_name.upper(), len(chunks),
        )
        return list(chunks)

    result = validate_retrieval(query, chunks, judge_llm)
    verdict = result["verdict"]

    irrelevant_idx: set[int] = set()
    if verdict != "UNKNOWN":
        for pc in result.get("per_chunk", []):
            if pc.get("relevant") is False and isinstance(pc.get("index"), int):
                irrelevant_idx.add(pc["index"])

    kept = [c for i, c in enumerate(chunks) if i not in irrelevant_idx]
    logger.debug(
        "[VALIDATE_%s] verdict=%s | kept %d/%d | query=%r",
        track_name.upper(), verdict, len(kept), len(chunks), query[:60],
    )
    return kept


def validate_document_retrieval(state: GraphState) -> dict:
    """Validate chunks from the documents collection.

    Runs in parallel with validate_learned_qa_retrieval after all retrieve
    branches complete (the retrieve fan-in barrier).
    """
    query = state.get("query") or state.get("user_input") or ""
    chunks = state.get("retrieved_document_chunks") or []
    kept = _validate_track("documents", chunks, query)
    return {"validated_document_chunks": kept}


def validate_learned_qa_retrieval(state: GraphState) -> dict:
    """Validate chunks from the learned_qa collection.

    Runs in parallel with validate_document_retrieval after all retrieve
    branches complete (the retrieve fan-in barrier).
    """
    query = state.get("query") or state.get("user_input") or ""
    chunks = state.get("retrieved_learned_qa_chunks") or []
    kept = _validate_track("learned_qa", chunks, query)
    return {"validated_learned_qa_chunks": kept}

import logging
from state import GraphState
from app_workflow.services.llm_setup import llm, judge_llm
from app_workflow.services.services import embedding_manager
from app_workflow.services.validators import validate_merge
from app_workflow.config import (
    ENABLE_RETRIEVAL_DEDUP_MERGE,
    ENABLE_RETRIEVAL_DEDUP_MERGE_VALIDATION,
    ENABLE_COMPRESSION_OUTPUT_FIX,
    MERGE_SIMILARITY_THRESHOLD,
)

logger = logging.getLogger(__name__)


def _run_dedup_merge(
    track_name: str,
    input_chunks: list[dict],
) -> tuple[list[dict], list[dict]]:
    """Deduplicate and merge near-duplicate chunks within one track.

    Returns (result_chunks, merge_pairs).  When ENABLE_RETRIEVAL_DEDUP_MERGE
    is False the input is returned unchanged and merge_pairs is empty.
    """
    if not input_chunks:
        logger.debug("[DEDUP_MERGE_%s] no chunks — skipping", track_name.upper())
        return [], []

    if not ENABLE_RETRIEVAL_DEDUP_MERGE:
        logger.debug(
            "[DEDUP_MERGE_%s] disabled — passing through %d chunk(s)",
            track_name.upper(), len(input_chunks),
        )
        return list(input_chunks), []

    # Embed every chunk for pairwise cosine comparison
    chunks_with_emb: list[dict] = []
    for c in input_chunks:
        content = (c.get("content") or "").strip()
        if not content:
            continue
        emb = embedding_manager.generate_embedding(content)
        chunks_with_emb.append({**c, "embedding": emb})

    # Identify near-duplicate groups
    claimed: set[int] = set()
    merge_groups: list[list[int]] = []
    for i in range(len(chunks_with_emb)):
        if i in claimed:
            continue
        group = [i]
        for j in range(i + 1, len(chunks_with_emb)):
            if j in claimed:
                continue
            sim = embedding_manager.cosine_similarity(
                chunks_with_emb[i]["embedding"],
                chunks_with_emb[j]["embedding"],
            )
            if sim >= MERGE_SIMILARITY_THRESHOLD:
                group.append(j)
                claimed.add(j)
        if len(group) > 1:
            claimed.add(i)
            merge_groups.append(group)

    logger.debug(
        "[DEDUP_MERGE_%s] %d chunk(s) → %d merge group(s) (threshold=%.2f)",
        track_name.upper(), len(chunks_with_emb), len(merge_groups), MERGE_SIMILARITY_THRESHOLD,
    )

    # Lazy import avoids circular dependency at module load time
    from nodes.nac import _merge_similar_chunks

    merge_pairs: list[dict] = []
    indices_to_drop: set[int] = set()

    for group in merge_groups:
        keeper_idx = group[0]
        source_chunks = [chunks_with_emb[i] for i in group]
        merged = _merge_similar_chunks(
            source_chunks,
            llm,
            embedding_manager,
            output_fix_enabled=ENABLE_COMPRESSION_OUTPUT_FIX,
        )
        chunks_with_emb[keeper_idx] = merged
        merge_pairs.append({"source_chunks": source_chunks, "merged": merged})
        indices_to_drop.update(group[1:])
        logger.info(
            "[DEDUP_MERGE_%s] merged %d near-duplicate chunk(s) from: %s",
            track_name.upper(), len(group),
            [chunks_with_emb[i].get("source", "?") for i in group],
        )

    result_chunks: list[dict] = []
    for i, c in enumerate(chunks_with_emb):
        if i in indices_to_drop:
            continue
        clean: dict = {"content": c["content"], "source": c["source"]}
        if "similarity_score" in c:
            clean["similarity_score"] = c["similarity_score"]
        if isinstance(c.get("chunk_seq"), int):
            clean["chunk_seq"] = c["chunk_seq"]
        result_chunks.append(clean)

    saved = len(chunks_with_emb) - len(result_chunks)
    logger.info(
        "[DEDUP_MERGE_%s] %d → %d chunk(s) (%d merged/eliminated)",
        track_name.upper(), len(chunks_with_emb), len(result_chunks), saved,
    )
    return result_chunks, merge_pairs

    Pass-through (no-op) when ENABLE_RETRIEVAL_DEDUP_MERGE_VALIDATION is False.
    Runs in parallel with validate_dedup_merge_learned_qa.

import logging
from state import GraphState

logger = logging.getLogger(__name__)


def combine_tracks(state: GraphState) -> dict:
    """Join learned_qa and document tracks into a single ordered list for compression.

    This is the fan-in point after both per-track dedup-merge validators complete.
    Learned-QA chunks are placed first because they have higher priority than raw
    document chunks, mirroring the precedence ordering in agent_query.py's
    format_precedence_context_for_llm().
    """
    learned_qa = state.get("dedup_merged_learned_qa_chunks") or []
    documents = state.get("dedup_merged_document_chunks") or []
    combined = [*learned_qa, *documents]
    logger.info(
        "[COMBINE_TRACKS] learned_qa=%d  documents=%d  combined=%d chunk(s)",
        len(learned_qa), len(documents), len(combined),
    )
    return {"dedup_merged_chunks": combined}

def fan_out_retrievals(state: GraphState):
    """Fan out one retrieve Send per query variant.

    Each Send runs retrieve() in parallel with query=variant.  retrieve() calls
    retrieve_separate() which queries both collections with a single embedding,
    writing to retrieved_document_chunks and retrieved_learned_qa_chunks via the
    Annotated(operator.add) reducers so all variant results accumulate.
    """
    return [
        Send("retrieve", {**state, "query": variant})
        for variant in state["query_variants"]
    ]


def route_user_input(state: GraphState) -> str:
    cmd = state.get("command", "")
    if cmd == "stats":
        return "cmd_stats"
    if cmd == "learn":
        return "cmd_learn"
    if cmd == "bad":
        return "cmd_bad"
    if cmd == "exit":
        return "cmd_exit"
    return "generate_query_variants"


def route_after_combine(state: GraphState) -> str:
    """Route after combine_tracks: empty result → no_context, else enter compression."""
    if not state.get("dedup_merged_chunks"):
        logger.warning("[ROUTE] all tracks empty after dedup-merge — routing to no_context_answer")
        return "no_context_answer"
    return "NAC"


def route_nac_to_validator(state: GraphState) -> str:
    return "validate_NAC" if ENABLE_COMPRESSION_VALIDATION else "DC"


def route_dc_to_validator(state: GraphState) -> str:
    return "validate_DC" if ENABLE_COMPRESSION_VALIDATION else "LBC"


def route_lbc_to_validator(state: GraphState) -> str:
    if ENABLE_COMPRESSION_VALIDATION:
        return "validate_LBC"
    if not state["compressed_docs"]:
        if state["retry_count"] >= LLM_RESPONSE_RETRY_LIMIT:
            logger.warning("Max retries reached with no relevant documents. Generating empty answer.")
            return "generate_answer"
        logger.warning(
            "No relevant documents after compression. Retrying (attempt %d).",
            state["retry_count"],
        )
        return "retry"
    return "generate_answer"


def route_after_compression(state: GraphState) -> str:
    if not state["compressed_docs"]:
        if state["retry_count"] >= LLM_RESPONSE_RETRY_LIMIT:

Answer briefly:
When the node combine_tracks is reached, does the NAC work on learned_qa and document chunks separately or together (one list)?
Together — one list.

combine_tracks writes {"dedup_merged_chunks": [*learned_qa, *documents]}, and execute_nac reads state.get("dedup_merged_chunks") as a single flat list. NAC then groups chunks by (source, consecutive chunk_seq) runs and merges neighbors — it has no concept of which track a chunk came from.

Answer briefly: learned_qa chunks dont have chunk_seq. How can NAC work on this single flat list?
You're right — NAC skips any chunk without chunk_seq:


eligible = [(i, c) for i, c in enumerate(accumulated_chunks) if isinstance(c.get("chunk_seq"), int)]
ineligible = [(i, c) for i, c in enumerate(accumulated_chunks) if not isinstance(c.get("chunk_seq"), int)]
Learned_qa chunks fall into ineligible and pass through unchanged. NAC only merges the eligible (document) chunks. Both lists are recombined at the end:


result_chunks.extend(c for _, c in ineligible)
So NAC effectively runs on document chunks only, and learned_qa chunks are appended as-is. It works correctly on the single flat list.

Answer briefly: Does DC and LBC apply on learned_qa chunks in this list?
DC: Yes, but only cross-chunk redundancy. If a learned_qa chunk contains a sentence that's also in a document chunk (or another learned_qa chunk) within the same sliding window, DC will remove the duplicate sentence from the non-keeper chunk. DC has no track awareness.

LBC: Yes, fully. LBC compresses every chunk in compressed_docs individually against the query — it doesn't distinguish learned_qa from document chunks.

So both DC and LBC apply to learned_qa chunks, which is correct behavior — redundancy removal and query-focused compression should apply regardless of source.

def _run_dc(chunks: list[dict]) -> tuple[list[dict], list[dict]]:
    """Core DC logic. Returns (result_chunks, dc_groups_per_window)."""
    window_size = DC_WINDOW_SIZE

    if len(chunks) < 2:
        return list(chunks), []

    result: list[dict] = [dict(c) for c in chunks]
    total_sentences_removed = 0
    dc_groups_per_window: list[dict] = []
    _source_tag_re = re.compile(r"\[Source:[^\]]*\]", re.IGNORECASE)

    for window_start in range(0, len(result), window_size):
        window_end = min(window_start + window_size, len(result))
        window = result[window_start:window_end]

        if len(window) < 2:
            continue

        blocks = []
        for local_i, chunk in enumerate(window):
            src = chunk.get("source", "?")
            content = _source_tag_re.sub("", (chunk.get("content") or "")).strip()
            blocks.append(f"--- chunk {local_i} (source: {src}) ---\n{content}")
        chunks_block = "\n\n".join(blocks)

        prompt = _DC_SCAN_PROMPT.format(chunks_block=chunks_block)
        logger.debug(
            f"\n  [DC] scanning window [{window_start}:{window_end}] ({len(window)} chunk(s))"
        )

        raw = ""

def _run_lbc(chunks: list[dict], query: str) -> tuple[list[dict], list[dict]]:
    """Core LBC logic. Returns (result_chunks, lbc_validation_pairs)."""
    instructions = _LBC_DEFAULT_INSTRUCTIONS
    min_retention_ratio = LBC_MIN_RETENTION_RATIO

    if not chunks:
        return [], []

    result: list[dict] = []
    lbc_validation_pairs: list[dict] = []
    total_chars_before = sum(len(c.get("content", "")) for c in chunks)
    total_chars_after = 0
    skipped = accepted = irrelevant_dropped = 0

    for idx, chunk in enumerate(chunks):
        original_content = (chunk.get("content") or "").strip()
        source = chunk.get("source", "?")

        if not original_content:
            result.append(chunk)
            skipped += 1
            continue

        prompt = _LBC_COMPRESS_PROMPT.format(
            query=query,
            instructions=instructions,
            source=source,
            content=original_content,
        )
        logger.debug(
            f"\n  [LBC] chunk {idx} — source: '{source[:60]}'  ({len(original_content)} chars)"
        )

        raw = ""
        parsed_lbc: dict | None = None
        for attempt in range(1, LLM_RESPONSE_RETRY_LIMIT + 1):
            lbc_result = llm_invoke(
                llm, [{"role": "system", "content": prompt}], caller_tag="LBC"
            )
            if not lbc_result.ok:
                if lbc_result.error_kind in (
                    LLMErrorKind.SERVER_ERROR,
                    LLMErrorKind.CONNECTION,
                    LLMErrorKind.TIMEOUT,
                ):
                    logger.warning(
                        f"  [LBC] chunk {idx}: transient error on attempt {attempt} "
                        f"({lbc_result.error_kind.name}) — retrying…"
                    )
                    raw = ""
                    continue
                logger.error(
                    f"  [LBC] chunk {idx}: non-retryable error on attempt {attempt} "
                    f"({lbc_result.error_kind.name}): "
                    f"{lbc_result.error_message[:200]} — keeping original"
                )
                raw = ""
                break

            if not raw:
                logger.warning(f"  [LBC] chunk {idx}: empty response on attempt {attempt}, retrying…")
                continue

            if ENABLE_COMPRESSION_OUTPUT_FIX and ENABLE_GLOBAL_LLM_OUTPUT_FIX:
                candidate, _ok = fix_llm_output("lbc_compress", raw, llm=llm)
            else:
                candidate = _parse_to_python(raw)
                _ok = candidate is not None
            if _ok and isinstance(candidate, dict) and "compressed" in candidate:
                parsed_lbc = candidate
                break
            logger.warning(
                f"  [LBC] chunk {idx}: failed to parse JSON on attempt {attempt}, retrying…"
            )

        if parsed_lbc is None:
            logger.warning(
                f"  [LBC] chunk {idx}: parse failed after {LLM_RESPONSE_RETRY_LIMIT} "
                f"attempt(s) — keeping original"
            )
            result.append(chunk)
            total_chars_after += len(original_content)
            skipped += 1
            continue

        compressed_text = (parsed_lbc.get("compressed") or "").strip()
        dropped_count = parsed_lbc.get("dropped_count", 0)
        lbc_reason = (parsed_lbc.get("reason") or "").strip()
        logger.debug(
            f"  [LBC] chunk {idx}: LLM produced {len(compressed_text)} chars "
            f"(dropped_count={dropped_count})  reason: {lbc_reason[:120]}"

            logger.debug(f"  [LBC] chunk {idx}: marked __IRRELEVANT__ by LLM — dropping chunk")
            irrelevant_dropped += 1
            continue

        retention = len(compressed_text) / max(len(original_content), 1)
        if retention < min_retention_ratio:
            logger.debug(
                f"  [LBC] chunk {idx}: retention ratio {retention:.2f} < "
                f"{min_retention_ratio} — keeping original (over-compression guard)"
            )
            result.append(chunk)
            total_chars_after += len(original_content)
            skipped += 1
            continue

        if len(compressed_text) > len(original_content):
            logger.debug(
                f"  [LBC] chunk {idx}: 'compressed' output expanded "
                f"({len(original_content)} → {len(compressed_text)} chars) "
                f"— keeping original (over-expansion guard)"
            )
            result.append(chunk)
            total_chars_after += len(original_content)
            skipped += 1
            continue

        if compressed_text == original_content:
            logger.debug(f"  [LBC] chunk {idx}: no change — keeping as-is")
            result.append(chunk)
            total_chars_after += len(original_content)
            skipped += 1
            continue

        compressed_chunk_dict = {**chunk, "content": compressed_text}
        lbc_validation_pairs.append({"original": chunk, "compressed": compressed_chunk_dict})
        result.append(compressed_chunk_dict)
        total_chars_after += len(compressed_text)
        accepted += 1
        logger.info(
            "  [LBC] chunk %d: compressed (%d → %d chars, −%d chars)",
            idx, len(original_content), len(compressed_text),
            len(original_content) - len(compressed_text),
        )

    saved_chars = total_chars_before - total_chars_after
    pct = (saved_chars / max(total_chars_before, 1)) * 100
    logger.debug(
        f"\n  [LBC] done — {len(chunks)} → {len(result)} chunk(s) "
        f"({irrelevant_dropped} dropped as irrelevant, "
        f"{accepted} compressed, {skipped} kept as-is)"
    )
    logger.debug(
        f"  [LBC] chars: {total_chars_before:,} → {total_chars_after:,} "
        f"(-{saved_chars:,} = {pct:.1f}% reduction)"
    )
    logger.debug(_THIN)
    return result, lbc_validation_pairs

logger = logging.getLogger(__name__)


def _build_context(compressed_docs: list[dict]) -> str:
    return "\n\n".join(
        f"[{i + 1}] {doc['content']}" for i, doc in enumerate(compressed_docs)
    )


def generate_answer(state: GraphState) -> dict:
    compressed_docs = state["compressed_docs"]
    user_input = state["user_input"]
    context = _build_context(compressed_docs)

    if not ENABLE_ANSWER_DRAFT_CREATION:
        prompt = (
            f"Answer the following question using only the provided context.\n"
            f"Question: {user_input}\n"
            f"Context:\n{context}\n"
            f"Answer:"
        )
        logger.debug("[GENERATE_ANSWER] PROMPT:\n%s", prompt)
        response = llm.invoke(prompt)
        answer = response.content
    else:
        draft_prompt = (
            f"Answer the following question using only the provided context. "
            f"Be thorough and complete.\n"
            f"Question: {user_input}\n"
            f"Context:\n{context}\n"
            f"Draft Answer:"
        )
        logger.debug("[GENERATE_ANSWER] draft prompt:\n%s", draft_prompt)
        draft_response = llm.invoke(draft_prompt)
        draft = draft_response.content
        logger.debug("[GENERATE_ANSWER] draft:\n%s", draft)

        if ENABLE_ANSWER_QUALITY_CHECK:
            quality_prompt = GROUNDING_PROMPT.format(
                query=user_input,
                context=context,
                answer=draft,
            )
            quality_result = llm_invoke(
                judge_llm,
                [{"role": "system", "content": quality_prompt}],
                caller_tag="ANSWER-QUALITY",
            )
            verdict_line = (quality_result.content or "OK").strip() if quality_result.ok else "OK"
            logger.info("[GENERATE_ANSWER] quality verdict: %s", verdict_line[:120])

            if verdict_line.startswith("INSUFFICIENT"):
                issue = verdict_line[len("INSUFFICIENT"):].strip().lstrip("—").strip()
                refine_prompt = (
                    f"Answer the following question using only the provided context.\n"
                    f"Question: {user_input}\n"
                    f"Context:\n{context}\n\n"
                    f"Your previous draft was flagged as insufficient:\n"
                    f"Draft: {draft}\n"
                    f"Issue: {issue}\n\n"
                    f"Write an improved answer that addresses the issue above:\n"
                    f"Answer:"
                )
                logger.debug("[GENERATE_ANSWER] refine prompt:\n%s", refine_prompt)
                refined_response = llm.invoke(refine_prompt)
                answer = refined_response.content
            else:
                answer = draft
        else:
            answer = draft

    logger.debug("[GENERATE_ANSWER] RESPONSE:\n%s", answer)
    logger.info("Assistant: %s", answer)

    sources = [{"source": d.get("source", "?")} for d in compressed_docs]
    feedback_store.log(
        query=user_input,
        answer=answer,
        sources=sources,
        quality="OK",
        document_retrieved_chunks=state.get("compressed_document_chunks") or [],
        learned_qa_retrieved_chunks=state.get("compressed_learned_qa_chunks") or [],
    )

    if ENABLE_AUTO_DISTILLATION and self_learner.should_learn():
        logger.info("[AUTO_DISTILLATION] threshold reached — running distillation")
        self_learner.run_distillation()

    return {"answer": answer}

The root cause is:

httpcore.ConnectError: [Errno 11001] getaddrinfo failed

This is a DNS resolution failure.

getaddrinfo() is the operating system function that converts a hostname into an IP address.

Before Groq can receive your request, Python tries to resolve something like:

api.groq.com

into an IP address.

That resolution failed, so the connection never started.

What the exception chain says
Level 1
httpcore.ConnectError: [Errno 11001] getaddrinfo failed

Meaning:

"I tried to resolve the hostname but Windows DNS lookup failed."

Level 2

httpx wraps that:

httpx.ConnectError: [Errno 11001] getaddrinfo failed
Level 3

The Groq SDK wraps that:

groq.APIConnectionError: Connection error.
Level 4

LangGraph reports which node failed:

During task with name 'generate_answer'

So the failing node is:

generate_answer.py
response = llm.invoke(prompt)
Most common causes
1. Invalid API base URL

You previously had this issue:

Unknown request URL:
/openai/v1/openai/v1/chat/completions

which suggests custom base URLs are being used.

Check:

print(os.getenv("GROQ_API_BASE"))
print(os.getenv("CUSTOM_API_BASE"))

If either contains:

https://api.groq.com/openai/v1

or

https://api.groq.com/openai/v1/

and the SDK appends another path, problems occur.

If the hostname itself is malformed:

https://api.groq.co
https://api.groq.comm
https://groq-api

you'll get exactly this DNS error.

2. No internet connection

Test:

import requests
print(requests.get("https://api.groq.com").status_code)

or

ping api.groq.com
3. DNS issue

Try:

nslookup api.groq.com

If that fails:

ipconfig /flushdns

or switch DNS to:

8.8.8.8
8.8.4.4
4. VPN / Proxy

Corporate VPNs and proxies commonly produce:

getaddrinfo failed

Try disabling VPN temporarily.

5. Environment variable corruption

Since your project uses .env files extensively, verify:

from dotenv import load_dotenv
import os

load_dotenv()

print("GROQ_API_KEY =", os.getenv("GROQ_API_KEY"))
