4. Rewrite FeedbackStore

Your current FeedbackStore.log() appends one JSON line to interactions.jsonl, and load_all() rereads the whole file every time. Replace that with Mongo inserts/queries.

from datetime import datetime, timezone
from mongo_store import db
from config import MIN_FEEDBACK_LEN

class FeedbackStore:
    def __init__(self):
        self.interactions = db.feedback_interactions
        self.thumbdowns = db.user_thumbdowns

    def log(self, query, answer, sources, quality,
            document_retrieved_chunks=None,
            learned_qa_retrieved_chunks=None,
            retrieved_chunks=None,
            request_id=""):

        record = {
            "ts": datetime.now(timezone.utc),
            "request_id": request_id,
            "query": query,
            "normalized_query": self._normalize_query(query),
            "answer": answer,
            "quality": quality,
            "sources": sources,
            "document_chunks": self._stored_chunks(document_retrieved_chunks),
            "learned_qa_chunks": self._stored_chunks(learned_qa_retrieved_chunks),
        }
        self.interactions.insert_one(record)

    def load_all(self):
        return list(self.interactions.find({}, {"_id": 0}).sort("ts", 1))

    def count(self):
        return self.interactions.count_documents({})

    def count_good(self):
        return self.interactions.count_documents({"quality": "OK"})

    def load_good(self, limit=None):
        cursor = self.interactions.find({"quality": "OK"}, {"_id": 0}).sort("ts", -1)
        if limit:
            cursor = cursor.limit(limit)
        return list(reversed(list(cursor)))

    def mark_last_bad(self, feedback="", variants=None):
        last = self.interactions.find_one(sort=[("ts", -1)])
        if not last:
            return False

        self.interactions.update_one(
            {"_id": last["_id"]},
            {"$set": {"quality": "USER_THUMBSDOWN"}}
        )

        feedback_clean = (feedback or "").strip()
        if feedback_clean and len(feedback_clean) >= MIN_FEEDBACK_LEN:
            self.thumbdowns.insert_one({
                "ts": datetime.now(timezone.utc),
                "original_query": last.get("query", ""),
                "normalized_query": self._normalize_query(last.get("query", "")),
                "bad_answer": last.get("answer", ""),
                "user_feedback": feedback_clean,
                "variants": variants or [],
                "request_id": last.get("request_id", ""),
            })
        return True

    def find_thumbdowns_for_query(self, query):
        return list(self.thumbdowns.find(
            {"normalized_query": self._normalize_query(query)},
            {"_id": 0}
        ).sort("ts", -1))

    @staticmethod
    def _normalize_query(q):
        return q.lower().strip()

7. Change ingestion tabular conversion

ingest.py currently converts CSV/Excel into physical JSON files before loading them. Better: create Documents directly from rows and avoid temp JSON completely.

from langchain_core.documents import Document

def _convert_tabular_to_documents(p: Path) -> list[Document]:
    df = pd.read_csv(p) if p.suffix.lower() == ".csv" else pd.read_excel(p)
    df = df.fillna("")
    docs = []
    for i, row in df.iterrows():
        docs.append(Document(
            page_content=json.dumps(row.to_dict(), ensure_ascii=False),
            metadata={"source": str(p), "row": int(i)}
        ))
    return docs

Current State
Three files in ../data/feedback/, all managed through feedback_store.py and helper functions in agent_query.py / api.py:

Proposed Plan
1. New app/db.py module
A single place for the MongoClient and collection accessors. The URI comes from an env var (e.g. MONGODB_URI), added to config.py. All three collections live on the same database (e.g. rag_db).

2. feedback_interactions collection
This is the cleanest migration:

log() → insert_one(doc)
load_all() → find({})
load_good() → find({"quality": "OK"})
mark_last_bad() — currently rewrites the whole file to change the last record. With MongoDB: find_one(sort=[("ts", -1)]) → update_one({"_id": ...}, {"$set": {"quality": "USER_THUMBSDOWN"}}). Atomic, no race condition.
3. user_thumbdowns collection
Each thumbdown entry becomes one document. The load-modify-save pattern disappears:

_append_thumbdown() → insert_one(doc)
find_thumbdowns_for_query() → find({"normalized_query": query})
4. failed_variants collection
Two valid approaches — worth discussing:

Option A — Keep in-memory dict, use MongoDB as persistence
Minimal code change. Load entire collection into a dict at startup ({doc["normalized_query"]: doc["variants"] for doc in find({})}), mutate in memory, write back with replace_one(..., upsert=True) on change. Behavior is identical to today.

Option B — Per-query DB lookups (no in-memory dict)
Cleaner. Lookup becomes find_one({"normalized_query": norm}). Append becomes update_one(..., {"$addToSet": {"variants": {"$each": fresh}}}, upsert=True). The in-memory failed_variants_store dict in agent_query.py and api.py is removed entirely.

I'd recommend Option B — the dict is small but it currently means two copies of the data exist simultaneously, and both api.py and agent_query.py maintain their own separate in-memory copies (potential divergence in a multi-worker setup). MongoDB removes that problem.

def get_client() -> MongoClient:
    global _client

        _client = MongoClient(uri)
        # Log without exposing credentials in the URI
        display = uri.split("@")[-1] if "@" in uri else uri
        logger.info("MongoDB client initialized (host=%s)", display)
    return _client


def get_db():

import logging
from datetime import datetime, timezone

from pymongo import DESCENDING

from db import interactions_col, thumbdowns_col
from config import MIN_FEEDBACK_LEN

logger = logging.getLogger(__name__)

# Re-exported so callers can do: from feedback_store import MIN_FEEDBACK_LEN
__all__ = ["FeedbackStore", "MIN_FEEDBACK_LEN"]


class FeedbackStore:
    def __init__(self):
        self._interactions = interactions_col()
        self._thumbdowns = thumbdowns_col()

    @staticmethod
    def _stored_chunks(chunks: list[dict] | None) -> list[dict]:
        return [
            {
                "content": chunk.get("content", ""),
                "source": chunk.get(
                    "source",
                    (chunk.get("metadata") or {}).get("source", "?"),
                ),
            }
            for chunk in (chunks or [])[:3]
            if chunk.get("content")
        ]

    @staticmethod
    def _split_legacy_chunks(chunks: list[dict] | None) -> tuple[list[dict], list[dict]]:
        documents: list[dict] = []
        learned_qa: list[dict] = []
        for chunk in chunks or []:
            source = chunk.get(
                "source",
                (chunk.get("metadata") or {}).get("source", "?"),
            )
            target = learned_qa if source == "learned_qa" else documents
            target.append(chunk)
        return documents, learned_qa

    # ── Write ────────────────────────────────────────────────────────────────

    def log(
        self,
        query: str,
        answer: str,
        sources: list[dict],
        quality: str,           # "OK" | "INSUFFICIENT" | "USER_THUMBSDOWN"
        document_retrieved_chunks: list[dict] | None = None,
        learned_qa_retrieved_chunks: list[dict] | None = None,
        retrieved_chunks: list[dict] | None = None,
        request_id: str = "",
    ) -> None:
        if (
            retrieved_chunks is not None
            and document_retrieved_chunks is None
            and learned_qa_retrieved_chunks is None
        ):
            document_retrieved_chunks, learned_qa_retrieved_chunks = (
                self._split_legacy_chunks(retrieved_chunks)
            )

        record = {
            "ts": datetime.now(timezone.utc).isoformat(),
            "request_id": request_id,
            "query": query,
            "answer": answer,
            "quality": quality,
            "sources": sources,
            "document_chunks": self._stored_chunks(document_retrieved_chunks),
            "learned_qa_chunks": self._stored_chunks(learned_qa_retrieved_chunks),
        }
        self._interactions.insert_one(record)
        logger.debug(
            "Interaction logged to MongoDB: request_id=%s quality=%s",
            request_id, quality,
        )

    # ── Read ─────────────────────────────────────────────────────────────────

    def load_all(self) -> list[dict]:
        return [
            {k: v for k, v in doc.items() if k != "_id"}
            for doc in self._interactions.find({})
        ]

    def count(self) -> int:
        return self._interactions.count_documents({})

    def count_good(self) -> int:
        return self._interactions.count_documents({"quality": "OK"})

    def load_good(self, limit: int | None = None) -> list[dict]:
        if limit:
            # Fetch last `limit` records in chronological order
            docs = list(
                self._interactions.find({"quality": "OK"}, {"_id": 0})
                .sort("ts", DESCENDING).limit(limit)
            )
            return list(reversed(docs))
        return list(self._interactions.find({"quality": "OK"}, {"_id": 0}))

    # ── User feedback ──────────────────────────────────────────────────────────

    @staticmethod
    def _normalize_query(q: str) -> str:
        return q.lower().strip()

    def mark_last_bad(
        self,
        feedback: str = "",
        variants: list[dict] | None = None,
    ) -> bool:
        """
        Update the last interaction's quality to USER_THUMBSDOWN.

        If `feedback` meets the minimum-length threshold, also persist a
        structured thumbdown entry with the query variants and retrieved chunks.
        """
        last = self._interactions.find_one(sort=[("ts", DESCENDING)])
        if not last:
            return False

        self._interactions.update_one(
            {"_id": last["_id"]},
            {"$set": {"quality": "USER_THUMBSDOWN"}},
        )
        logger.info(
            "Interaction marked USER_THUMBSDOWN in MongoDB: request_id=%s",
            last.get("request_id", ""),
        )

        feedback_clean = (feedback or "").strip()
        if feedback_clean and len(feedback_clean) >= MIN_FEEDBACK_LEN:
            self._append_thumbdown(
                original_query=last.get("query", ""),
                bad_answer=last.get("answer", ""),
                feedback=feedback_clean,
                variants=variants or [],
                request_id=last.get("request_id", ""),
            )
        return True

    def _append_thumbdown(
        self,
        original_query: str,
        bad_answer: str,
        feedback: str,
        variants: list[dict],
        request_id: str = "",
    ) -> None:
        normalized = self._normalize_query(original_query)
        doc = {
            "ts": datetime.now(timezone.utc).isoformat(),
            "request_id": request_id,
            "original_query": original_query,
            "normalized_query": normalized,
            "bad_answer": bad_answer,
            "user_feedback": feedback,
            "variants": [
                {
                    "query": v.get("query", ""),
                    "document_chunks": [
                        {
                            "content": (c.get("content") or "")[:1000],
                            "source": c.get("source", "?"),
                        }
                        for c in (v.get("document_chunks") or v.get("chunks") or [])
                    ],
                    "learned_qa_chunks": [
                        {
                            "content": (c.get("content") or "")[:1000],
                            "source": c.get("source", "?"),
                        }
                        for c in (v.get("learned_qa_chunks") or [])
                    ],
                }
                for v in variants
            ],
        }
        self._thumbdowns.insert_one(doc)
        logger.info(
            "Thumbdown persisted to MongoDB: request_id=%s normalized_query=%r",
            request_id, normalized,
        )

    def find_thumbdowns_for_query(self, query: str) -> list[dict]:
        """Return all prior thumbdown entries whose normalized query matches `query`."""
        norm = self._normalize_query(query)
        return [
            {k: v for k, v in doc.items() if k != "_id"}
            for doc in self._thumbdowns.find({"normalized_query": norm})
        ]

def get_client() -> MongoClient:
    global _client
    if _client is None:

        _client = MongoClient(uri)

    return _client


def get_db():
    db_name = os.getenv("MONGODB_DB_NAME", "rag_db")

    db = get_db()

import logging
from datetime import datetime, timezone

from pymongo import DESCENDING

from app_workflow.services.db import interactions_col, thumbdowns_col, failed_variants_col
from app_workflow.config import MIN_FEEDBACK_LEN

logger = logging.getLogger(__name__)

__all__ = ["FeedbackStore", "MIN_FEEDBACK_LEN"]


class FeedbackStore:
    def __init__(self):
        self._interactions = interactions_col()
        self._thumbdowns = thumbdowns_col()
        self._failed_variants = failed_variants_col()

    @staticmethod
    def _stored_chunks(chunks: list[dict] | None) -> list[dict]:
        return [
            {
                "content": chunk.get("content", ""),
                "source": chunk.get(
                    "source",
                    (chunk.get("metadata") or {}).get("source", "?"),
                ),
            }
            for chunk in (chunks or [])[:3]
            if chunk.get("content")
        ]

    @staticmethod
    def _split_legacy_chunks(chunks: list[dict] | None) -> tuple[list[dict], list[dict]]:
        documents: list[dict] = []
        learned_qa: list[dict] = []
        for chunk in chunks or []:
            source = chunk.get(
                "source",
                (chunk.get("metadata") or {}).get("source", "?"),
            )
            target = learned_qa if source == "learned_qa" else documents
            target.append(chunk)
        return documents, learned_qa

    # ── Write ────────────────────────────────────────────────────────────────

    def log(
        self,
        query: str,
        answer: str,
        sources: list[dict],
        quality: str,           # "OK" | "INSUFFICIENT" | "USER_THUMBSDOWN"
        document_retrieved_chunks: list[dict] | None = None,
        learned_qa_retrieved_chunks: list[dict] | None = None,
        retrieved_chunks: list[dict] | None = None,
        request_id: str = "",
        variants: list[dict] | None = None,
    ) -> None:
        if (
            retrieved_chunks is not None
            and document_retrieved_chunks is None
            and learned_qa_retrieved_chunks is None
        ):
            document_retrieved_chunks, learned_qa_retrieved_chunks = (
                self._split_legacy_chunks(retrieved_chunks)
            )

        record: dict = {
            "ts": datetime.now(timezone.utc).isoformat(),
            "query": query,
            "answer": answer,
            "quality": quality,
            "sources": sources,
            "document_chunks": self._stored_chunks(document_retrieved_chunks),
            "learned_qa_chunks": self._stored_chunks(learned_qa_retrieved_chunks),
            "variants": variants or [],
        }
        # Only store request_id when set so the sparse unique index is not violated
        # by multiple CLI-path records that would all have the same empty string.
        if request_id:
            record["request_id"] = request_id

        self._interactions.insert_one(record)
        logger.debug(
            "Interaction logged to MongoDB: request_id=%s quality=%s",
            request_id, quality,
        )

    # ── Read ─────────────────────────────────────────────────────────────────

    def load_all(self) -> list[dict]:
        return [
            {k: v for k, v in doc.items() if k != "_id"}
            for doc in self._interactions.find({})
        ]

    def count(self) -> int:
        return self._interactions.count_documents({})

    def count_good(self) -> int:
        return self._interactions.count_documents({"quality": "OK"})

    def load_good(self, limit: int | None = None) -> list[dict]:
        if limit:
            docs = list(
                self._interactions.find({"quality": "OK"}, {"_id": 0})
                .sort("ts", DESCENDING).limit(limit)
            )
            return list(reversed(docs))
        return list(self._interactions.find({"quality": "OK"}, {"_id": 0}))

    # ── User feedback ─────────────────────────────────────────────────────────

    @staticmethod
    def _normalize_query(q: str) -> str:
        return q.lower().strip()

    def mark_last_bad(
        self,
        feedback: str = "",
        variants: list[dict] | None = None,
    ) -> bool:
        last = self._interactions.find_one(sort=[("ts", DESCENDING)])
        if not last:
            return False

        self._interactions.update_one(
            {"_id": last["_id"]},
            {"$set": {"quality": "USER_THUMBSDOWN"}},
        )
        logger.info(
            "Interaction marked USER_THUMBSDOWN in MongoDB: request_id=%s",
            last.get("request_id", ""),
        )

        feedback_clean = (feedback or "").strip()
        if feedback_clean and len(feedback_clean) >= MIN_FEEDBACK_LEN:
            self._append_thumbdown(
                original_query=last.get("query", ""),
                bad_answer=last.get("answer", ""),
                feedback=feedback_clean,
                variants=variants or [],
                request_id=last.get("request_id", ""),
            )
        return True

    def _append_thumbdown(
        self,
        original_query: str,
        bad_answer: str,
        feedback: str,
        variants: list[dict],
        request_id: str = "",
    ) -> None:
        normalized = self._normalize_query(original_query)
        doc = {
            "ts": datetime.now(timezone.utc).isoformat(),
            "request_id": request_id,
            "original_query": original_query,
            "normalized_query": normalized,
            "bad_answer": bad_answer,
            "user_feedback": feedback,
            "variants": [
                {
                    "query": v.get("query", ""),
                    "document_chunks": [
                        {
                            "content": (c.get("content") or "")[:1000],
                            "source": c.get("source", "?"),
                        }
                        for c in (v.get("document_chunks") or v.get("chunks") or [])
                    ],
                    "learned_qa_chunks": [
                        {
                            "content": (c.get("content") or "")[:1000],
                            "source": c.get("source", "?"),
                        }
                        for c in (v.get("learned_qa_chunks") or [])
                    ],
                }
                for v in variants
            ],
        }
        self._thumbdowns.insert_one(doc)
        logger.info(
            "Thumbdown persisted to MongoDB: request_id=%s normalized_query=%r",
            request_id, normalized,
        )

    def find_thumbdowns_for_query(self, query: str) -> list[dict]:
        norm = self._normalize_query(query)
        return [
            {k: v for k, v in doc.items() if k != "_id"}
            for doc in self._thumbdowns.find({"normalized_query": norm})
        ]

    # ── Failed variants ───────────────────────────────────────────────────────

    def load_failed_variants(self, query: str) -> list[str]:
        norm = self._normalize_query(query)
        doc = self._failed_variants.find_one({"normalized_query": norm})
        return list(doc["variants"]) if doc else []

    def save_failed_variants(self, query: str, variants: list[str]) -> None:
        if not variants:
            return
        norm = self._normalize_query(query)
        self._failed_variants.update_one(
            {"normalized_query": norm},
            {"$addToSet": {"variants": {"$each": variants}}},
            upsert=True,
        )
        logger.info(
            "[FAILED VARIANTS] saved %d variant(s) to MongoDB for norm=%r",
            len(variants), norm,
        )

Step 3: What is a replica set?

A replica set is multiple MongoDB servers that keep identical copies of the database.

Example:

               Primary
           (Accepts Writes)
                  │
          Replicates Changes
          ↙               ↘
     Secondary         Secondary

Every write goes to the primary.

The primary immediately tells the secondaries:

"I just inserted this document. Copy it."

So all three eventually contain identical data.

Step 4: Why does MongoDB need a replica set for transactions?

Imagine your code:

Update Collection A
Insert into Collection B

You want both operations to succeed together.

If the server crashes after the first operation:

✓ Collection A updated

✗ Collection B not updated

The database is inconsistent.

A transaction promises:

Either both operations happen, or neither happens.

To guarantee this, MongoDB needs a mechanism called the oplog (operations log).

Step 5: What is the oplog?

Every write is recorded in a special log.

Example:

1. Update interaction
2. Insert thumbdown
3. Commit transaction

If something crashes, MongoDB can read this log and decide:

Was the transaction committed?

YES
→ Keep both writes.

NO
→ Roll everything back.

This log is only maintained in replica set mode.

Standalone MongoDB doesn't maintain the infrastructure needed for transactions.

Step 6: Why not support transactions on standalone?

This is mostly a MongoDB design decision.

Internally, transactions rely on components that only exist when the server is configured as a replica set:

oplog
logical sessions
transaction coordinator
commit protocol

Rather than maintaining two completely different transaction implementations, MongoDB simply enables transactions only in replica set mode.

Step 7: Why is a single-node replica set enough?

This confuses many beginners.

A replica set does not mean multiple computers.

You can have:

    ▼

No secondary.

No replication.

But MongoDB still enables:

sessions
transaction machinery

because it knows this server is part of a replica set.

Thought for 15s
Core diagnosis

Your problem is shared quota contention.

Groq rate limits are applied at the organization level, not independently per API request/user. Limits include RPM, RPD, TPM, TPD, and sometimes separate input/output TPM limits. You hit whichever limit is exhausted first. Groq also returns 429 Too Many Requests, retry-after, and rate-limit headers such as remaining tokens and reset time.

So the real issue is:

Multiple parallel requests are independently retrying against the same shared Groq token bucket, without global coordination.

Exponential backoff helps only after failure. It does not prevent requests from colliding again.

Best solutions, ranked
1. Add a global LLM rate limiter / token scheduler

This is the most correct production solution.

Instead of every request directly calling Groq, all LLM calls should pass through one shared component:

API Request 1 ┐
API Request 2 ├──> LLM Gateway / Token Scheduler ──> Groq
API Request 3 ┘

The scheduler should track:

remaining_requests
remaining_tokens
reset_tokens_time
retry_after
estimated_input_tokens
reserved_output_tokens

Before making a Groq call, it decides:

Do we have enough token budget now?
Yes -> call Groq
No  -> queue/delay/fail fast

This prevents request 2 from blindly calling Groq while request 1 has already consumed the available TPM.

2. Use a queue instead of raw parallel LLM calls

Keep your API parallel, but serialize or partially serialize only the LLM section.

Example:

Retrieval / validation / preprocessing  -> parallel
LLM call                                -> controlled queue
Postprocessing                          -> parallel

This is much better than putting a lock around the whole API request.

Bad:

async with global_lock:
    run_entire_pipeline()

Better:

run_retrieval_parallel()

await llm_queue.submit(llm_call)

run_postprocessing_parallel()

This keeps most of your app concurrent while protecting the bottleneck.

3. Respect Groq’s retry-after header

Do not use blind exponential backoff only.

Groq explicitly provides retry-after when rate-limited, and rate-limit headers are available for remaining/reset information. A real issue reported in Aider showed that ignoring Groq’s retry-after and using custom retry timing caused poor retry behavior.

Correct behavior:

if status_code == 429:
    wait = response.headers.get("retry-after")
    await asyncio.sleep(float(wait))

Then add small jitter only if needed.

Before sending a request, estimate:

input_tokens + max_output_tokens

Then reserve that amount from a shared token bucket.

Important: max_tokens matters. If you set max_tokens=4096, your scheduler should assume the call may need that much output budget, even if it often generates less.

Production rule:

estimated_cost = input_tokens + max_output_tokens

If budget is insufficient, queue the call.

- Reduce retrieved chunks
- Compress context before final generation
- Use smaller system prompts
- Cache repeated prompts
- Lower max_tokens

def _run_lbc(chunks, query):

3. DC's Windowed Scan Can Be Parallelized Across Non-Overlapping Windows
In dc.py, _run_dc() slides a window of size DC_WINDOW_SIZE=3 across chunks sequentially. Windows are non-overlapping (range(0, len(result), window_size)), so they're actually independent of each other and can be processed in parallel:

from concurrent.futures import ThreadPoolExecutor

def _run_dc_parallel(chunks):
    windows = [
        (start, min(start + DC_WINDOW_SIZE, len(chunks)))
        for start in range(0, len(chunks), DC_WINDOW_SIZE)
    ]
    with ThreadPoolExecutor(max_workers=4) as executor:
        futures = [
            executor.submit(_process_window, chunks[s:e], s)
            for s, e in windows
        ]
        results = [f.result() for f in futures]
    # merge results back in order
    return [chunk for window_result in results for chunk in window_result]
This is safe because each window operates on its own slice and you reconstruct order after.

This is O(N²) comparisons. With N=20 chunks from multiple variants you get 190 cosine similarity calls. Each call is a numpy dot product (fast, but called individually). You can vectorize the entire pairwise matrix in one shot:

import numpy as np

def _find_near_duplicates(chunks_with_emb, threshold):
    embs = np.stack([c["embedding"] for c in chunks_with_emb])  # shape: (N, D)
    # Compute full similarity matrix in one matmul — O(N²) but vectorized
    sim_matrix = embs @ embs.T  # cosine since embeddings are normalized
    
    claimed = set()
    merge_groups = []
    for i in range(len(chunks_with_emb)):
        if i in claimed:
            continue
        group = [i]
        for j in range(i + 1, len(chunks_with_emb)):
            if j not in claimed and sim_matrix[i, j] >= threshold:
                group.append(j)
                claimed.add(j)
        if len(group) > 1:
            claimed.add(i)
            merge_groups.append(group)
    return merge_groups
The key change is embs @ embs.T — a single matrix multiply that computes all N² similarities at once via BLAS, rather than N² individual numpy dot products with Python function call overhead each. For N=20 this is ~10–20x faster for that step.

def reciprocal_rank_fusion(ranked_lists: list[list[dict]], k: int = 60) -> list[dict]:
    scores: dict[str, float] = {}
    chunk_map: dict[str, dict] = {}
    for ranked_list in ranked_lists:
        for rank, chunk in enumerate(ranked_list):
            key = chunk["content"][:100]  # content fingerprint
            scores[key] = scores.get(key, 0) + 1.0 / (k + rank + 1)
            chunk_map[key] = chunk
    return sorted(chunk_map.values(), key=lambda c: scores[c["content"][:100]], reverse=True)

20. The _apply_cooldown Sleep Happens After Every Single LLM Call — Make It Adaptive to Queue Depth
Your current cooldown logic in llm_caller.py sleeps _cooldown_floor after every successful call if the queue is non-empty. But during compression of a single query, you have a burst of many calls in rapid succession, all queued up, all sleeping between themselves. The cooldown is designed to prevent 429s — but Groq's rate limit is measured over a sliding 1-minute window, not per-call.

Replace the fixed per-call cooldown with a token budget tracker that only sleeps when you're close to the window limit:

python
class TokenBudgetTracker:
    def __init__(self, tpm_limit: int = 6000, window_seconds: int = 60):
        self.tpm_limit = tpm_limit
        self.window_seconds = window_seconds
        self.calls: list[tuple[float, int]] = []  # (timestamp, tokens_used)
    
    def record_call(self, tokens_used: int):
        now = time.monotonic()
        self.calls = [(t, tok) for t, tok in self.calls if now - t < self.window_seconds]
        self.calls.append((now, tokens_used))
    
    def sleep_if_needed(self):
        now = time.monotonic()
        recent = [(t, tok) for t, tok in self.calls if now - t < self.window_seconds]
        used = sum(tok for _, tok in recent)
        if used > self.tpm_limit * 0.85:  # 85% threshold
            oldest = min(t for t, _ in recent)
            sleep_until = oldest + self.window_seconds
            sleep_time = sleep_until - now
            if sleep_time > 0:
                time.sleep(sleep_time)
This way you only sleep when you're actually about to hit the limit, not after every single call. For bursts under the TPM budget (which is common for short chunks), you get zero cooldown between calls.

22. validate_nac_documents Iterates Merge Pairs But Never Modifies State — It's Pure Logging
Looking at validate_nac_documents in nac.py: it iterates over nac_merge_pairs_documents, calls validate_merge, logs the result, and returns {}. It makes one LLM call per merge pair but never uses the verdict to do anything — it doesn't reject bad merges, doesn't update state, doesn't route differently. The same is true for validate_dedup_merge_documents and validate_dedup_merge_learned_qa.

These are observability-only nodes right now. Unless you're actively using the logged verdicts to improve the system, they're pure latency cost. You have two options:

Option A — Make them actually functional: Route back if UNFAITHFUL, replacing the bad merge with the original chunks. This adds value proportional to the LLM cost.

Option B — Downgrade to sampling: Only validate 1 in N merge pairs rather than all of them:

python
VALIDATION_SAMPLE_RATE = 0.3  # validate 30% of pairs

pairs_to_validate = random.sample(pairs, max(1, int(len(pairs) * VALIDATION_SAMPLE_RATE)))
for pair in pairs_to_validate:
    check = validate_merge(...)
This maintains observability at a fraction of the LLM call cost.
