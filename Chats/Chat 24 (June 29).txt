Good. I have a complete picture of your pipeline. You've already covered the obvious mechanical solutions — let me give you genuinely different angles that attack the problem from a different level of the stack.

1. Speculative Single-Variant Execution ("Fast Path First")
Instead of always fanning out all variants in parallel, execute only the highest-confidence variant first, speculatively. If that single retrieve returns chunks above a quality threshold (e.g. count ≥ N and average similarity score ≥ X), commit to it and skip the remaining variants entirely. Only fan out the others when the first retrieve comes back weak.

This flips your current model: instead of "generate all, run all, merge", it becomes "generate all, run best, conditionally run rest."

The key insight is that for a large fraction of queries — especially short, unambiguous, factual ones — the best variant almost always dominates anyway. You're currently paying full cost for all variants even when one of them immediately finds high-scoring chunks that the others will just duplicate.

Implementation: You already have similarity_score on every retrieved chunk in retrieve.py. After the first retrieve Send completes, evaluate the result. In LangGraph this requires restructuring fan_out_retrievals into a two-phase conditional — a "speculative retrieve" node followed by a routing decision — rather than a pure fan-out. It's a graph topology change, but a surgical one.

2. Query Variant Diversity Scoring via Disjoint Term Sets (No Embeddings Needed)
Before fanning out, compute the Jaccard distance on stemmed term sets between every pair of variants. This is O(n²) on 2–3 strings — essentially free, zero model calls, zero GPU, pure Python set operations.

python
from nltk.stem import PorterStemmer
stemmer = PorterStemmer()

def term_set(query):
    stopwords = {"the", "a", "an", "of", "in", "for", "what", "is", "are", "how"}
    return {stemmer.stem(w) for w in query.lower().split() if w not in stopwords}

def jaccard_similarity(q1, q2):
    s1, s2 = term_set(q1), term_set(q2)
    if not s1 | s2:
        return 1.0
    return len(s1 & s2) / len(s1 | s2)
Two variants with Jaccard similarity > 0.7 are almost certainly asking for the same corpus region. Drop the one with the lower specificity score (measured as term count or inverse of common stopword ratio). This catches the class of redundancy that cosine similarity on embeddings can miss — paraphrases that share rare domain-specific terms but differ in surface structure will both score high similarity in embedding space AND have high Jaccard overlap, giving you a second independent signal with zero latency cost.

3. Retrieval Result Saturation Detection ("Good Enough" Signal)
Your pipeline currently has no concept of "we have enough unique information — stop." Add a marginal utility check at the retrieve level: after each variant's chunks come back, compute what fraction of those chunks are truly novel relative to what's already accumulated (using your existing similarity_score infrastructure or chunk IDs).

If variant N's chunks are >80% already-seen (by ID or near-duplicate cosine), emit a saturated=True flag on that variant's result. Then in fan_out_retrievals, any pending variants could be cancelled if saturation is reached.

The practical challenge in LangGraph is that Send is fire-and-forget — you can't cancel an already-dispatched branch mid-flight. So you implement this as a gate node after all retrieves complete but before the expensive compression pipeline starts. At that gate, check saturation and short-circuit: if accumulated unique chunks already exceed a quality bar, route directly toward combine_tracks with what you have, skipping NAC/DC/LBC entirely for the saturated variants' contributions (which are already dedup-merged anyway).

The compression pipeline is where your real per-variant LLM call cost lives. Saturation detection at the retrieve level prevents that cost from being incurred on redundant data.

4. Offline Variant Clustering via Historical Interaction Data
You have feedback_interactions in MongoDB with variants logged on every run. Mine that data. Cluster the historical variant strings for each normalized query (or query family) using your embedding model offline, and observe which clusters always retrieve the same chunks. That gives you a learned set of "equivalent reformulation families" for your corpus.

At generation time, you don't filter variants — you constrain the LLM's generation toward underrepresented cluster regions. In _build_system_prompt, inject something like:

"The following query angles have historically retrieved overlapping content for this topic — do NOT generate variants in these directions: [cluster centroids of known-redundant families]."

This is fundamentally different from all your current options because it learns from your actual retrieval history rather than making a structural decision at runtime. Over time it becomes self-improving. The redundancy you experienced on run 100 prevents wasted work on run 101. This pairs naturally with your existing blocked_variants mechanism — it's the same infrastructure extended with cluster-awareness rather than per-query exact matching.

5. Structured Query Decomposition Instead of Paraphrase Generation
The root cause of redundant variants is that you're asking the LLM to generate paraphrases of the same query. Paraphrases are semantically equivalent by design, so redundancy is almost inevitable. The alternative is to change what you're generating.

Instead of "generate 2–3 different ways to ask the same question," instruct the LLM to decompose the query into orthogonal sub-questions — each targeting a genuinely distinct information need.

For example, "What is the refund policy for enterprise contracts?" should decompose into: refund eligibility conditions, refund timeline and process, enterprise contract special terms — not three paraphrases of "refund policy enterprise." These sub-queries are structurally different corpus targets. They won't retrieve the same chunks because they're not asking for the same thing.

This requires a prompt redesign in _build_system_prompt — replace the paraphrase instruction with a decomposition instruction — and it changes what _PROCESS_INSTRUCTIONS says about query generation. The practical benefit is that redundancy drops dramatically by construction, not by filtering after the fact. The tradeoff is that it may sometimes over-decompose simple queries into sub-questions that don't individually find good chunks, so you'd want to keep the original query as the always-included baseline variant.

Use Jaccard as a cheap pre-filter, cosine as a targeted disambiguator — but only when Jaccard is in the grey zone:

python
def should_drop_variant(q1, q2, embedding_manager, threshold_jaccard=0.75, threshold_cosine=0.93):
    j = jaccard(q1, q2)
    
    if j >= threshold_jaccard:
        return True   # obvious lexical duplicate — drop, no embedding needed
    
    if j < 0.3:
        return False  # clearly diverse — keep, no embedding needed
    
    # Grey zone (0.3–0.75): pay for one cosine check
    e1 = embedding_manager.generate_embedding(q1)
    e2 = embedding_manager.generate_embedding(q2)
    return embedding_manager.cosine_similarity(e1, e2) >= threshold_cosine
This way, the ~49 pairs (6.3%) with J≥0.8 and the clear lexical duplicates are dropped for free. The 136 pairs (17.5%) with J<0.2 are kept for free. Embedding calls only fire for the genuinely ambiguous middle — and that's where they actually add value. On 2–3 variants, worst case you pay for 1–2 embedding calls, not 3.

The threshold numbers to tune from your data: J=0.75 as the "definitely redundant" cutoff catches the blatant cases without touching the grey zone, and cosine 0.93 is deliberately high to avoid dropping variants like "early signs of ASD in toddlers" vs "ASD screening in young children" (J=0.143, semantically close but targeting slightly different corpus regions — early behavioral signs vs. screening instrument results).

## Behaviour requirements

1. **Threshold constants** — define at module level, easy to tune:
   ```python
   PRE_RETRIEVAL_SIM_THRESHOLD = 0.85   # cosine sim between user_query and variant
   ```

2. **Normalisation** — before any similarity or dedup check, strip and lowercase
   the query string consistently.

3. **Failed variants** — load from `feedback_store.load_failed_variants(user_query)`
   at the start of `run_test`. A variant is skipped (status `"SKIPPED_FAILED_STORE"`)
   if its normalised form matches any entry in the loaded list.

4. **Redundant variants store** — after the run, persist any newly discovered
   `FAILED_VARIANT` entries via `feedback_store.save_failed_variants()`.
   Do NOT persist `REDUNDANT_PRE` or `REDUNDANT_POST` variants — those are
   query-specific artefacts, not persistent failures.

5. **Pre-retrieval filter** — compares each variant against the **user_query**
   embedding (not pairwise between variants), using threshold
   `PRE_RETRIEVAL_SIM_THRESHOLD`.  Log the sim score for every variant.

6. **Post-retrieval filter** — operates on **document track only** first, then
   separately on **learned_qa track**. A variant is `REDUNDANT_POST` only if
   it contributes zero new IDs in BOTH tracks combined versus all prior
   variants.  First-seen variant is always kept.

7. **Adaptive budget** — `adaptive_branch_budget` must be called BEFORE the LLM
   prompt, so the prompt can include the budget in its instruction:
   ```
   "Generate exactly {max_variants} sub-question(s)."
   ```
   Pass `max_variants` into the prompt builder so the instruction is embedded
   in the system prompt sent to the LLM.

8. **Orthogonal prompt** — `build_orthogonal_system_prompt` must reuse the exact
   same blocked-variants and thumbdown formatting logic from `_build_system_prompt`
   in `query_variants.py`.  Do not duplicate the string-building — factor it into
   a shared helper `_append_blocked_and_thumbdowns(parts, blocked, thumbdowns)`
   used by both the original and the new builder.

9. **`__main__` block** — include a block at the bottom with 3–5 representative
   test queries of varying complexity (at least one simple lookup, one moderate,
   one multi-aspect). For each query, run `run_test` twice:
   once with `use_orthogonal_prompt=False`, once with `True`.
   Print a comparison header between the two runs showing:
   - Number of raw variants
   - Number surviving pre-filter
   - Number surviving post-filter
   - Unique chunk IDs retrieved in total

10. **Logging** — use the project's existing `logging` infrastructure.
    Each step function should emit at least one `logger.debug` and one
    `logger.info` line with a consistent `[TEST_PLAN]` tag prefix.

11. **Timing** — wrap each of the 6 functional steps (variant gen, pre-filter,
    retrieve, post-filter, budget, prompt-build) with `time.perf_counter()`
    and store the durations in `TestRunResult.step_times`.

# ── Shared prompt helper ──────────────────────────────────────────────────────

def _append_blocked_and_thumbdowns(
    parts: list[str],
    blocked_variants: list[str],
    prior_thumbdowns: list[dict] | None,
) -> None:
    """Append blocked-variants and thumbdown blocks to *parts* in-place.

    Used by both _build_paraphrase_system_prompt and build_orthogonal_system_prompt
    so the formatting logic is never duplicated.
    """
    if blocked_variants:
        lines = "\n".join(f'  - "{v}"' for v in blocked_variants)
        parts.append(
            "BLOCKED QUERY VARIANTS — These exact phrasings retrieved 0 useful chunks"
            " the last time this question was asked. Do NOT reuse them under any"
            " circumstances. Generate different, semantically distinct reformulations:"
            f"\n{lines}"
        )

    if not prior_thumbdowns:
        return

    # Passive (history) block — mirroring _build_system_prompt in query_variants.py
    td_block = (
        "USER-FLAGGED PRIOR FAILURE — This same question (or a near-identical one)"
        " was asked before and the user explicitly marked the answer as bad. Below is"
        " what went wrong last time, including the exact query reformulations that were"
        " tried and the chunks they retrieved.\n"
        "  1. AVOID re-using the same query reformulations — they led to a bad answer.\n"
        "  2. AVOID grounding your answer in the same chunks unless you can clearly"
        " interpret them differently.\n"
        "  3. Try genuinely different angles, vocabulary, and sub-topics.\n"
    )
    for i, td in enumerate(prior_thumbdowns, start=1):
        td_block += f"\n--- Prior failure #{i} ---\n"
        td_block += f"Original query : {td.get('original_query', '')}\n"
        ufb = td.get("user_feedback", "")
        if ufb:
            td_block += f"User feedback  : {ufb}\n"
        bad_ans = td.get("bad_answer", "")
        if bad_ans:
            snippet = bad_ans[:300] + ("..." if len(bad_ans) > 300 else "")
            td_block += f"Bad answer was : {snippet}\n"
        variants = td.get("variants", []) or []
        if variants:
            td_block += "Reformulations that were tried (DO NOT REUSE):\n"
            for v in variants:
                td_block += f'  - "{v.get("query", "")}"\n'
                doc_cks = v.get("document_chunks", v.get("chunks", [])) or []
                qa_cks = v.get("learned_qa_chunks", []) or []
                for track_name, chunks in (("learned_qa", qa_cks), ("documents", doc_cks)):
                    for c in chunks[:2]:
                        content = (c.get("content") or "").replace("\n", " ")
                        preview = content[:200] + ("..." if len(content) > 200 else "")
                        td_block += (
                            f"      retrieved {track_name} "
                            f"[{c.get('source', '?')}]: {preview}\n"
                        )
    parts.append(td_block)

    # Active (recency-bias) feedback block — appended last so the model notices it
    feedback_lines = [
        f'  - "{(td.get("user_feedback") or "").strip()}"'
        for td in prior_thumbdowns
        if (td.get("user_feedback") or "").strip()
    ]
    if feedback_lines:
        parts.append(
            "PRIORITY — USER FEEDBACK MUST BE ADDRESSED\n"
            "The user previously flagged an answer to this exact question as bad and"
            " told you specifically what was missing or wrong:\n"
            + "\n".join(feedback_lines)
            + "\n\nYou MUST generate at least one retrieve_documents query that directly"
            " targets the topics or facts described in this feedback. Do not treat"
            " this as a passive hint — it is your primary retrieval objective."
        )

def _build_paraphrase_system_prompt(
    blocked_variants: list[str],
    prior_thumbdowns: list[dict] | None,
    max_variants: int,
) -> str:
    parts: list[str] = [_ROLE_AND_RULES]
    parts.append(
        f"Generate exactly {max_variants} semantically different paraphrase(s) of the"

        " that paraphrase as the query.\n"
        "Rules:\n"
        f"  - Do NOT call retrieve_documents more than {max_variants} times.\n"
        "  - Each paraphrase must approach the question from a different linguistic angle.\n"
        "  - Queries must be short, concrete noun-phrases — not full sentences."

def build_orthogonal_system_prompt(

    prior_thumbdowns: list[dict] | None,
    max_variants: int = 3,
) -> str:
    """Build a system prompt that asks the LLM to decompose the question orthogonally."""
    parts: list[str] = [_ROLE_AND_RULES]
    parts.append(

        f" Generate exactly {max_variants} sub-question(s)."
        " Each sub-question must target a DIFFERENT FACTUAL DIMENSION of the topic."
        " Forbidden: rephrasing the same question, synonyms for the same concept,"
        " or narrowing/broadening the same angle."
        " Good orthogonal axes: cause vs effect, definition vs application,"
        " historical context vs current state, mechanism vs outcome."
        " For each sub-question call retrieve_documents ONCE with that sub-question as the query."
    )
    _append_blocked_and_thumbdowns(parts, blocked_variants, prior_thumbdowns)
    return "\n\n".join(parts)


# ── Step 5: adaptive branch budget ────────────────────────────────────────────

def adaptive_branch_budget(user_query: str) -> int:
    """Cheap no-LLM heuristic: return how many variants are worth generating."""
    logger.debug("[TEST_PLAN] adaptive_branch_budget: query=%r", user_query[:80])
    word_count = len(user_query.split())
    has_conjunction = any(
        w in user_query.lower()
        for w in ["and", "or", "both", "versus", "vs", "compare",
                  "difference", "how", "why", "explain"]
    )
    if word_count <= 4 and not has_conjunction:
        budget = 1   # simple lookup
    elif word_count <= 8 or not has_conjunction:
        budget = 2   # moderate
    else:
        budget = 3   # complex / multi-aspect
    logger.info(
        "[TEST_PLAN] budget=%d (words=%d, has_conjunction=%s)",
        budget, word_count, has_conjunction,
    )
    return budget


# ── Step 1: variant generation ─────────────────────────────────────────────────

def generate_query_variants_for_test(
    user_query: str,
    blocked: list[str],
    thumbdowns: list[dict] | None,
    *,
    max_variants: int = 3,
    use_orthogonal_prompt: bool = False,
    _prebuilt_prompt: str | None = None,
) -> list[str]:
    """Build system prompt, call LLM with tool schema, parse retrieve_documents calls."""
    logger.debug(
        "[TEST_PLAN] generate_query_variants_for_test: query=%r max=%d orthogonal=%s",
        user_query[:80], max_variants, use_orthogonal_prompt,
    )
    if _prebuilt_prompt is not None:
        system_prompt = _prebuilt_prompt
    elif use_orthogonal_prompt:
        system_prompt = build_orthogonal_system_prompt(blocked, thumbdowns, max_variants)
    else:
        system_prompt = _build_paraphrase_system_prompt(blocked, thumbdowns, max_variants)

    messages = [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": user_query},
    ]

    result = llm_invoke(
        llm,
        messages,
        tools=[RETRIEVE_DOCUMENTS_TOOL_SCHEMA],
        caller_tag="TEST-PLAN-VARIANTS",
    )

    raw_variants: list[str] = []
    if result.ok:
        tool_calls = getattr(result.response, "tool_calls", []) or []
        logger.debug("[TEST_PLAN] LLM returned %d tool_call(s)", len(tool_calls))
        seen: set[str] = set()
        for tc in tool_calls:
            if tc.get("name") == "retrieve_documents":
                q = (tc.get("args") or {}).get("query", "").strip()
                if q and q.lower() not in seen:
                    raw_variants.append(q)
                    seen.add(q.lower())
    else:
        logger.warning(
            "[TEST_PLAN] LLM call failed (%s) — falling back to user query",
            result.error_kind,
        )

    if not raw_variants:
        logger.warning("[TEST_PLAN] No variants produced — using user query as fallback")
        raw_variants = [user_query]

    logger.info("[TEST_PLAN] %d raw variant(s): %s", len(raw_variants), raw_variants)
    return raw_variants


# ── Step 2: pre-retrieval filter ──────────────────────────────────────────────

def pre_retrieval_filter(
    user_query: str,
    raw_variants: list[str],
    threshold: float = PRE_RETRIEVAL_SIM_THRESHOLD,
) -> tuple[list[str], list[str], dict[str, float]]:
    """Drop variants whose cosine sim with user_query >= threshold (near-duplicates of the query)."""
    logger.debug(
        "[TEST_PLAN] pre_retrieval_filter: %d variants, threshold=%.2f",
        len(raw_variants), threshold,
    )
    emb: EmbeddingManager = _get_resources()["embedding_manager"]

    user_emb = emb.generate_embedding(user_query.strip().lower())
    kept: list[str] = []
    redundant: list[str] = []
    sims: dict[str, float] = {}

    for variant in raw_variants:
        var_emb = emb.generate_embedding(variant.strip().lower())
        sim = emb.cosine_similarity(user_emb, var_emb)
        sims[variant] = sim
        logger.debug("[TEST_PLAN]   sim=%.4f  %r", sim, variant[:60])
        if sim >= threshold:
            redundant.append(variant)
            logger.debug("[TEST_PLAN]   → REDUNDANT_PRE (sim=%.4f >= threshold=%.2f)", sim, threshold)
        else:
            kept.append(variant)

    logger.info(
        "[TEST_PLAN] pre_retrieval_filter: kept=%d, redundant=%d",
        len(kept), len(redundant),
    )
    return kept, redundant, sims


# ── Step 3: retrieval ─────────────────────────────────────────────────────────

def retrieve_all(
    kept_variants: list[str],
    failed_variants: list[str],
) -> list[VariantResult]:
    """Retrieve from both tracks for each kept variant; skip those in failed store."""
    logger.debug("[TEST_PLAN] retrieve_all: %d variant(s)", len(kept_variants))
    failed_set = {v.strip().lower() for v in failed_variants}
    retriever: RAGRetriever = _get_resources()["retriever"]

    results: list[VariantResult] = []
    for variant in kept_variants:
        if variant.strip().lower() in failed_set:
            logger.info("[TEST_PLAN]   SKIPPED_FAILED_STORE: %r", variant[:60])
            results.append(VariantResult(query=variant, status="SKIPPED_FAILED_STORE"))
            continue

        logger.debug("[TEST_PLAN]   retrieving: %r", variant[:60])
        retrieved = retriever.retrieve_separate(
            variant,
            top_k=RETRIEVAL_TOP_K,
            top_l=RETRIEVAL_TOP_L,
            score_threshold=MIN_SIMILARITY,
        )
        doc_chunks = retrieved["documents"]
        qa_chunks = retrieved["learned_qa"]
        status = "FAILED_VARIANT" if (not doc_chunks and not qa_chunks) else "OK"

        if status == "FAILED_VARIANT":
            logger.info("[TEST_PLAN]   FAILED_VARIANT (empty): %r", variant[:60])
        else:
            logger.debug("[TEST_PLAN]   OK: docs=%d qa=%d", len(doc_chunks), len(qa_chunks))

        results.append(VariantResult(
            query=variant,
            doc_chunks=doc_chunks,
            qa_chunks=qa_chunks,
            status=status,
        ))

    logger.info("[TEST_PLAN] retrieve_all: %d result(s)", len(results))
    return results


# ── Step 4: post-retrieval filter ─────────────────────────────────────────────

def post_retrieval_filter(
    variant_results: list[VariantResult],
) -> tuple[list[VariantResult], list[str], dict]:
    """
    Keep variants that contribute at least one new chunk ID across both tracks.
    The first OK variant is always kept. FAILED/SKIPPED variants are excluded.
    """
    logger.debug("[TEST_PLAN] post_retrieval_filter: %d result(s)", len(variant_results))
    seen_doc_ids: set[str] = set()
    seen_qa_ids: set[str] = set()
    id_overlap_map: dict[str, list[str]] = {}
    kept: list[VariantResult] = []
    redundant: list[str] = []

    for vr in variant_results:
        if vr.status != "OK":
            continue

        this_doc_ids = {c["id"] for c in vr.doc_chunks if "id" in c}
        this_qa_ids  = {c["id"] for c in vr.qa_chunks  if "id" in c}

        # Build frequency map: chunk_id → queries that retrieved it
        for cid in this_doc_ids | this_qa_ids:
            id_overlap_map.setdefault(cid, []).append(vr.query)

        new_doc = this_doc_ids - seen_doc_ids
        new_qa  = this_qa_ids  - seen_qa_ids
        is_first = not seen_doc_ids and not seen_qa_ids

        if is_first or new_doc or new_qa:
            kept.append(vr)
            seen_doc_ids.update(this_doc_ids)
            seen_qa_ids.update(this_qa_ids)
            logger.debug(
                "[TEST_PLAN]   KEPT (first=%s new_doc=%d new_qa=%d): %r",
                is_first, len(new_doc), len(new_qa), vr.query[:60],
            )
        else:
            redundant.append(vr.query)
            logger.info("[TEST_PLAN]   REDUNDANT_POST: %r", vr.query[:60])

    logger.info(
        "[TEST_PLAN] post_retrieval_filter: kept=%d, redundant=%d",
        len(kept), len(redundant),
    )
    return kept, redundant, id_overlap_map


# ── Orchestrator ──────────────────────────────────────────────────────────────

def run_test(
    user_query: str,
    use_orthogonal_prompt: bool = False,
) -> TestRunResult:
    style = "orthogonal" if use_orthogonal_prompt else "paraphrase"
    logger.info("[TEST_PLAN] === run_test query=%r style=%s ===", user_query[:80], style)
    step_times: dict[str, float] = {}
    resources = _get_resources()
    feedback_store: FeedbackStore = resources["feedback_store"]

    # Step: budget (no LLM call)
    t0 = time.perf_counter()
    max_variants = adaptive_branch_budget(user_query)
    step_times["budget"] = time.perf_counter() - t0

    # Load persistent store data
    failed_variants = feedback_store.load_failed_variants(user_query)
    failed_set = {v.strip().lower() for v in failed_variants}
    thumbdowns = feedback_store.find_thumbdowns_for_query(user_query) or None

    # Step: prompt build (pure string construction, no LLM)
    t0 = time.perf_counter()
    if use_orthogonal_prompt:
        system_prompt = build_orthogonal_system_prompt([], thumbdowns, max_variants)
    else:
        system_prompt = _build_paraphrase_system_prompt([], thumbdowns, max_variants)
    step_times["prompt_build"] = time.perf_counter() - t0

    # Step: variant generation (LLM call)
    t0 = time.perf_counter()
    raw_variants = generate_query_variants_for_test(
        user_query,
        blocked=[],
        thumbdowns=thumbdowns,
        max_variants=max_variants,
        use_orthogonal_prompt=use_orthogonal_prompt,
        _prebuilt_prompt=system_prompt,
    )
    step_times["variant_gen"] = time.perf_counter() - t0

    # Cap to budget; remove already-failed variants before pre-filter
    raw_variants = raw_variants[:max_variants]
    non_failed = [v for v in raw_variants if v.strip().lower() not in failed_set]

    # Step: pre-retrieval filter
    t0 = time.perf_counter()
    pre_kept, pre_redundant, pre_sims = pre_retrieval_filter(user_query, non_failed)
    step_times["pre_filter"] = time.perf_counter() - t0

    # Step: retrieve
    t0 = time.perf_counter()
    variant_results = retrieve_all(pre_kept, failed_variants)
    step_times["retrieve"] = time.perf_counter() - t0

    # Step: post-retrieval filter
    t0 = time.perf_counter()
    post_kept, post_redundant, id_overlap_map = post_retrieval_filter(variant_results)
    step_times["post_filter"] = time.perf_counter() - t0

    # Persist newly discovered FAILED_VARIANT entries (not REDUNDANT_PRE/POST)
    new_failed = [vr.query for vr in variant_results if vr.status == "FAILED_VARIANT"]
    if new_failed:
        feedback_store.save_failed_variants(user_query, new_failed)
        logger.info("[TEST_PLAN] persisted %d new failed variant(s)", len(new_failed))

    return TestRunResult(
        user_query=user_query,
        prompt_style=style,
        max_variants=max_variants,
        raw_variants=raw_variants,
        pre_filter_kept=pre_kept,
        pre_filter_redundant=pre_redundant,
        pre_filter_sims=pre_sims,
        variant_results=variant_results,
        post_filter_kept=post_kept,
        post_filter_redundant=post_redundant,
        id_overlap_map=id_overlap_map,
        step_times=step_times,
    )


# ── Report printer ────────────────────────────────────────────────────────────

def log_report(result: TestRunResult) -> None:
    _S = "─" * 70

    def _section(title: str) -> None:
        print(f"\n{_S}\n  {title}\n{_S}")

    _section(f"[QUERY]  {result.user_query}")
    print(f"  Prompt style : {result.prompt_style}")

    _section("[BUDGET]")
    print(f"  max_variants = {result.max_variants}")

    _section("[VARIANTS RAW]")
    for i, v in enumerate(result.raw_variants, 1):
        print(f"  {i:2d}. {v}")
    if not result.raw_variants:
        print("  (none)")

    _section(f"[FILTER PRE]  threshold={PRE_RETRIEVAL_SIM_THRESHOLD:.2f}")
    print(f"  Kept ({len(result.pre_filter_kept)}):")
    for v in result.pre_filter_kept:
        sim = result.pre_filter_sims.get(v, float("nan"))
        print(f"    +[{sim:.4f}]  {v}")
    print(f"  Redundant ({len(result.pre_filter_redundant)}):")
    for v in result.pre_filter_redundant:
        sim = result.pre_filter_sims.get(v, float("nan"))
        print(f"    -[{sim:.4f}]  {v}")

    skipped = [vr.query for vr in result.variant_results if vr.status == "SKIPPED_FAILED_STORE"]
    _section("[FILTER FAILED]")
    if skipped:
        for v in skipped:
            print(f"  SKIP: {v}")
    else:
        print("  (none)")

    _section("[RETRIEVAL]")
    for vr in result.variant_results:
        print(
            f"  [{vr.status:<22s}]  "
            f"docs={len(vr.doc_chunks):2d}  qa={len(vr.qa_chunks):2d}  "
            f"{vr.query[:55]}"
        )
    if not result.variant_results:
        print("  (none)")

    _section("[FILTER POST]")
    print(f"  Kept ({len(result.post_filter_kept)}):")
    for vr in result.post_filter_kept:
        print(f"    +  {vr.query}")
    print(f"  Redundant ({len(result.post_filter_redundant)}):")
    for v in result.post_filter_redundant:
        print(f"    -  {v}")
    multi = {k: v for k, v in result.id_overlap_map.items() if len(v) > 1}
    if multi:
        print(f"  Overlapping chunk IDs ({len(multi)}):")
        for cid, queries in list(multi.items())[:5]:
            print(f"    {cid[:28]}…  shared by {len(queries)} variant(s)")

    _section("[CHUNK SUMMARY]")
    all_doc_ids: set[str] = set()
    all_qa_ids:  set[str] = set()
    for vr in result.variant_results:
        if vr.status == "OK":
            all_doc_ids.update(c.get("id", "") for c in vr.doc_chunks)
            all_qa_ids.update(c.get("id", "") for c in vr.qa_chunks)
    print(f"  Unique doc chunk IDs : {len(all_doc_ids)}")
    print(f"  Unique qa  chunk IDs : {len(all_qa_ids)}")

    _section("[TIMING]")
    for step, secs in result.step_times.items():
        print(f"  {step:<20s}: {secs:.3f}s")

    print(f"\n{_S}")

def adaptive_branch_budget(user_query: str) -> int:
    """Return how many variants are worth generating based on query complexity."""
    word_count = len(user_query.split())
    has_conjunction = any(
        w in user_query.lower()
        for w in BRANCH_BUDGET_CONJUNCTION_KEYWORDS
    )
    if word_count <= BRANCH_BUDGET_SHORT_WORD_COUNT and not has_conjunction:
        budget = 1
    elif word_count <= BRANCH_BUDGET_MEDIUM_WORD_COUNT or not has_conjunction:
        budget = 2

        budget = 3
    logger.debug(
        "[QUERY_VARIANTS] budget=%d (words=%d, has_conjunction=%s)",
        budget, word_count, has_conjunction,
    )

def pre_retrieval_filter(
    user_query: str,
    raw_variants: list[str],
    inter_variant_threshold: float = PRE_RETRIEVAL_SIM_THRESHOLD,
    max_variants: int | None = None,
) -> tuple[list[str], list[str]]:
    """
    Phase 1: Pairwise inter-variant dedup — drop variants too similar to an
             already-kept variant (greedy, first occurrence wins).
    Phase 2: Rank survivors by cosine similarity to user_query (descending)
             and cap to max_variants.

    Returns (kept, redundant).
    """
    if not raw_variants:
        return [], []

    # Phase 1: inter-variant pairwise deduplication
    variant_embs: list[tuple[str, list]] = [
        (v, embedding_manager.generate_embedding(v.strip().lower()))
        for v in raw_variants
    ]
    kept_embs: list[tuple[str, list]] = []
    redundant: list[str] = []

    for variant, var_emb in variant_embs:
        is_redundant = any(
            embedding_manager.cosine_similarity(var_emb, kept_emb) >= inter_variant_threshold
            for _, kept_emb in kept_embs
        )
        if is_redundant:
            redundant.append(variant)
            logger.debug("[QUERY_VARIANTS] pre_filter inter-dup dropped: %r", variant[:60])
        else:
            kept_embs.append((variant, var_emb))

    # Phase 2: rank by similarity to user_query; cap to budget
    user_emb = embedding_manager.generate_embedding(user_query.strip().lower())
    sims: dict[str, float] = {
        v: embedding_manager.cosine_similarity(user_emb, ve) for v, ve in kept_embs
    }
    sorted_kept = sorted(sims, key=sims.__getitem__, reverse=True)

    if max_variants is not None and len(sorted_kept) > max_variants:
        capped = sorted_kept[max_variants:]
        redundant.extend(capped)
        sorted_kept = sorted_kept[:max_variants]
        logger.debug("[QUERY_VARIANTS] pre_filter budget cap: dropped %d", len(capped))

    logger.info(
        "[QUERY_VARIANTS] pre_retrieval_filter: kept=%d, redundant=%d",
        len(sorted_kept), len(redundant),
    )
    return sorted_kept, redundant


def _build_system_prompt(
    blocked_variants: list[str],
    prior_thumbdowns: list[dict] | None = None,
    max_variants: int = 3,
) -> str:
    """Mirror of agent_query._build_system_prompt — same ordering and blocks."""
    parts = [_ROLE_AND_RULES]

    parts.append(
        f"RETRIEVAL BUDGET — Call retrieve_documents exactly {max_variants} time(s)"
        " for this query. Do NOT exceed this limit."
    )

    if blocked_variants:
        lines = "\n".join(f'  - "{v}"' for v in blocked_variants)
        parts.append(
            "BLOCKED QUERY VARIANTS — These exact phrasings retrieved 0 useful chunks"
            " the last time this question was asked. Do NOT reuse them under any"
            " circumstances. Generate different, semantically distinct reformulations:"
            f"\n{lines}"
        )

    if prior_thumbdowns:
        # ── Passive block: what went wrong (near _ROLE_AND_RULES) ────────────
        td_history_block = (
            "USER-FLAGGED PRIOR FAILURE — This same question (or a near-identical one)"
            " was asked before and the user explicitly marked the answer as bad. Below is"
            " what went wrong last time, including the exact query reformulations that were"
            " tried and the chunks they retrieved.\n"
            "  1. AVOID re-using the same query reformulations — they led to a bad answer.\n"
            "  2. AVOID grounding your answer in the same chunks unless you can clearly"
            " interpret them differently.\n"
            "  3. Try genuinely different angles, vocabulary, and sub-topics.\n"
        )
        for i, td in enumerate(prior_thumbdowns, start=1):
            td_history_block += f"\n--- Prior failure #{i} ---\n"
            td_history_block += f"Original query : {td.get('original_query', '')}\n"
            ufb = td.get("user_feedback", "")
            if ufb:
                td_history_block += f"User feedback  : {ufb}\n"
            bad_ans = td.get("bad_answer", "")
            if bad_ans:
                snippet = bad_ans[:300] + ("..." if len(bad_ans) > 300 else "")
                td_history_block += f"Bad answer was : {snippet}\n"
            variants = td.get("variants", []) or []
            if variants:
                td_history_block += "Reformulations that were tried (DO NOT REUSE):\n"
                for v in variants:
                    td_history_block += f'  - "{v.get("query", "")}"\n'
                    document_chunks = v.get("document_chunks", v.get("chunks", [])) or []
                    learned_qa_chunks = v.get("learned_qa_chunks", []) or []
                    for track_name, chunks in (
                        ("learned_qa", learned_qa_chunks),
                        ("documents", document_chunks),
                    ):
                        for c in chunks[:2]:
                            content = (c.get("content") or "").replace("\n", " ")
                            preview = content[:200] + ("..." if len(content) > 200 else "")
                            td_history_block += (
                                f"      retrieved {track_name} "
                                f"[{c.get('source', '?')}]: {preview}\n"
                            )
        parts.append(td_history_block)

    # PROCESS goes after the history context — same position as in agent_query.py
    parts.append(_PROCESS_INSTRUCTIONS)

    if prior_thumbdowns:
        # ── Active block: what to seek — appended LAST so recency bias helps ──
        feedback_lines = []
        for td in prior_thumbdowns:
            ufb = (td.get("user_feedback") or "").strip()
            if ufb:
                feedback_lines.append(f'  - "{ufb}"')
        if feedback_lines:
            fb_str = "\n".join(feedback_lines)
            active_block = (
                "PRIORITY — USER FEEDBACK MUST BE ADDRESSED\n"
                "The user previously flagged an answer to this exact question as bad and"
                " told you specifically what was missing or wrong:\n"
                f"{fb_str}\n\n"
                "You MUST generate at least one retrieve_documents query that directly"
                " targets the topics or facts described in this feedback. Do not treat"
                " this as a passive hint — it is your primary retrieval objective."
            )
            parts.append(active_block)

    return "\n\n".join(parts)


def generate_query_variants(state: GraphState) -> dict:
    _t0 = time.perf_counter()
    user_query = state["user_input"]

    if not ENABLE_SUB_QUERY_GENERATION:
        logger.debug("[QUERY_VARIANTS] sub-query generation disabled — using original query")
        timing_tracker.record("Sub-Query Generation", time.perf_counter() - _t0)
        return {"query_variants": [user_query], "retry_count": state["retry_count"] + 1}

    max_variants = adaptive_branch_budget(user_query)

    blocked_variants: list[str] = list(state.get("blocked_variants") or [])  # type: ignore[arg-type]
    prior_thumbdowns: list[dict] = list(state.get("prior_thumbdowns") or [])  # type: ignore[arg-type]

    system_prompt = _build_system_prompt(
        blocked_variants,
        prior_thumbdowns if prior_thumbdowns else None,
        max_variants,
    )
    messages = [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": user_query},
    ]

    logger.debug("[QUERY_VARIANTS] Invoking LLM with retrieve_documents tool schema")
    result = llm_invoke(
        llm,
        messages,
        tools=[RETRIEVE_DOCUMENTS_TOOL_SCHEMA],
        caller_tag="QUERY-VARIANTS",
    )

    raw_variants: list[str] = []

    if result.ok:
        tool_calls = getattr(result.response, "tool_calls", []) or []
        logger.debug("[QUERY_VARIANTS] LLM returned %d tool call(s)", len(tool_calls))
        seen: set[str] = set()
        for tc in tool_calls:
            if tc.get("name") == "retrieve_documents":
                q = (tc.get("args") or {}).get("query", "").strip()
                if q and q.lower() not in seen:
                    raw_variants.append(q)
                    seen.add(q.lower())
    else:
        logger.warning(
            "[QUERY_VARIANTS] LLM call failed (%s) — falling back to user query",
            result.error_kind,
        )

    if not raw_variants:
        logger.warning("[QUERY_VARIANTS] No retrieve_documents calls produced — falling back to user query")
        raw_variants = [user_query]

    # Strip variants that are known to have failed for this query
    blocked_set = {v.strip().lower() for v in blocked_variants}
    non_failed = [v for v in raw_variants if v.strip().lower() not in blocked_set]
    if not non_failed:
        non_failed = raw_variants  # all blocked — keep originals as fallback

    # Pre-retrieval filter: inter-variant dedup (≥0.95 sim) then rank+cap to budget
    query_variants, _ = pre_retrieval_filter(user_query, non_failed, max_variants=max_variants)
    if not query_variants:
        query_variants = non_failed[:max_variants] or [user_query]

    logger.debug(
        "[QUERY_VARIANTS] %d query variant(s) after filter: %s",
        len(query_variants), query_variants,
    )

    timing_tracker.record("Sub-Query Generation", time.perf_counter() - _t0)
    # Each variant is dispatched to a parallel `retrieve` node via fan_out_retrievals
    # (routes.py Send mechanism) — that is where each tool-call query runs in parallel.
    return {"query_variants": query_variants, "retry_count": state["retry_count"] + 1}

def post_retrieval_filter_node(state: GraphState) -> dict:
    """Discard variant contributions whose combined chunk content is identical to a
    previously kept variant, then write the cleaned lists to post_filtered_* fields
    for downstream validation.

    Uses (content, source) pairs as chunk identity since the flat retrieved lists
    don't carry vector-store IDs. Chunk data (similarity_score, chunk_seq) is
    preserved by filtering the accumulated retrieved_* lists rather than
    reconstructing from variants_with_chunks.
    """
    _t0 = time.perf_counter()

    variants = state.get("variants_with_chunks") or []
    all_doc_chunks = state.get("retrieved_document_chunks") or []
    all_qa_chunks = state.get("retrieved_learned_qa_chunks") or []

    seen_sets: set[frozenset] = set()
    kept_keys: set[tuple] = set()   # (content, source) pairs that belong to kept variants
    redundant: list[str] = []

    for vr in variants:
        doc_chunks = vr.get("document_chunks") or []
        qa_chunks = vr.get("learned_qa_chunks") or []
        combined = frozenset(
            (c.get("content", ""), c.get("source", ""))
            for c in (doc_chunks + qa_chunks)
        )
        if not combined:
            # variant retrieved nothing — skip, don't add to redundant
            continue
        if combined in seen_sets:
            redundant.append(vr.get("query", ""))
            logger.info("[POST_FILTER] redundant variant: %r", vr.get("query", "")[:60])
        else:
            seen_sets.add(combined)
            kept_keys.update(combined)

    if not redundant:
        # Fast path: nothing to filter
        filtered_doc = list(all_doc_chunks)
        filtered_qa = list(all_qa_chunks)
    else:
        filtered_doc = [
            c for c in all_doc_chunks
            if (c.get("content", ""), c.get("source", "")) in kept_keys
        ]
        filtered_qa = [
            c for c in all_qa_chunks
            if (c.get("content", ""), c.get("source", "")) in kept_keys
        ]

    logger.info(
        "[POST_FILTER] redundant_variants=%d  doc=%d→%d  qa=%d→%d",
        len(redundant),
        len(all_doc_chunks), len(filtered_doc),
        len(all_qa_chunks), len(filtered_qa),
    )
    timing_tracker.record("Post-Retrieval Filter", time.perf_counter() - _t0)
    return {
        "post_filtered_document_chunks": filtered_doc,
        "post_filtered_learned_qa_chunks": filtered_qa,
    }

#!/usr/bin/env python3
"""
Extract structured RAG pipeline events from debug log files in app_workflow/run_logs/.

Usage:
  python extract_logs.py                          # summary of all logs
  python extract_logs.py --output json            # write .extracted.json per log
  python extract_logs.py --output both --combine  # json + summary + combined file
  python extract_logs.py --file path/to/file.log  # single file
  python extract_logs.py --filter 20260623        # only files matching pattern
"""

import re
import json
import argparse
from pathlib import Path
from typing import Optional


# ─── Regex patterns ───────────────────────────────────────────────────────────

RE_LOG_LINE = re.compile(
    r"^(?P<ts>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})"
    r" \| (?P<level>\w+)\s+"
    r"\| (?P<module>[\w.\-]+)"
    r" \| (?P<msg>.*)"
)

RE_QUERY_VARIANTS = re.compile(
    r"\[QUERY_VARIANTS\] (\d+) query variant\(s\):\s*\[(.+)\]"
)

RE_EMBEDDING_QUERY = re.compile(r'Query\s*:\s*"(.+)"')
RE_EMBEDDING_MODEL = re.compile(r"Model\s*:\s*(.+)")
RE_EMBEDDING_SHAPE = re.compile(r"Shape\s*:\s*\((\d+),\)")
RE_EMBEDDING_VALS  = re.compile(r"First 8 vals\s*:\s*\[(.+)\]")
RE_EMBEDDING_NORM  = re.compile(r"L2 norm\s*:\s*([\d.]+)")

RE_COLLECTION_PARAMS = re.compile(
    r"Querying collections separately - documents top_k=(\d+), learned_qa top_l=(\d+), score_threshold=([\d.]+)"
)
RE_COLLECTION_TIMING = re.compile(
    r"\[retriever\] collection '(\w+)' retrieval took ([\d.]+)s"
)

RE_RANKED_HEADER = re.compile(r"Ranked (\d+) result\(s\) from (\w+) after")
RE_RANKED_ITEM   = re.compile(r"(\w+)\[(\d+)\]\s*-\s*score:\s*([\d.]+)\s+\[(.+)\]")
RE_RANKED_PREVIEW = re.compile(r"preview:\s*(.+)")

RE_RETRIEVE_NODE = re.compile(
    r"\[RETRIEVE\] query='(.+?)'\s+docs=(\d+)\s+learned_qa=(\d+)"
)

RE_VALIDATE_VERDICT = re.compile(
    r"\[VALIDATE-RETRIEVAL\] verdict=(\w+)\s+relevant=(\d+)/(\d+)"
)
RE_VALIDATE_REASON = re.compile(r"\[VALIDATE-RETRIEVAL\] reason:\s*(.+)")
RE_VALIDATE_CHUNK  = re.compile(r"([✓✗])\s+chunk\s+(\d+):\s*(.+)")

RE_VALIDATE_NODE = re.compile(
    r"\[VALIDATE_(\w+)\] verdict=(\w+)\s+\|\s+kept\s+(\d+)/(\d+)\s+\|\s+query='(.+?)'"
)

RE_ENCODE_TIME = re.compile(
    r"\[embedding\] model\.encode\(\) on '(.+?)' took ([\d.]+)s"
)

RE_SEPARATOR = re.compile(r"^[─\-─\s]+$")


# ─── Parser ───────────────────────────────────────────────────────────────────

def parse_log_file(path: Path) -> dict:
    session = {
        "file": path.name,
        "query_variants": [],
        "embedding_steps": [],
        "collection_queries": [],
        "collection_timings": [],
        "ranked_results": [],
        "retrieve_nodes": [],
        "validation_events": [],
        "validate_nodes": [],
        "encode_times": [],
    }

    lines = path.read_text(encoding="utf-8", errors="replace").splitlines()

    current_embedding: Optional[dict] = None
    current_ranked: Optional[dict] = None
    current_validation: Optional[dict] = None

    def flush_embedding():
        nonlocal current_embedding
        if current_embedding and current_embedding.get("query"):
            session["embedding_steps"].append(current_embedding)
        current_embedding = None

    def flush_ranked():
        nonlocal current_ranked
        if current_ranked and current_ranked.get("items"):
            session["ranked_results"].append(current_ranked)
        current_ranked = None

    def flush_validation():
        nonlocal current_validation
        if current_validation and current_validation.get("verdict"):
            session["validation_events"].append(current_validation)
        current_validation = None

    for raw in lines:
        m = RE_LOG_LINE.match(raw)
        if m:
            ts     = m.group("ts")
            module = m.group("module")
            msg    = m.group("msg").strip()
        else:
            ts     = None
            module = None
            msg    = raw.strip()

        if not msg or RE_SEPARATOR.match(msg):
            continue

        # ── Query variants ─────────────────────────────────────────────────
        mv = RE_QUERY_VARIANTS.search(msg)
        if mv:
            variants = re.findall(r"'([^']*)'", mv.group(2))
            session["query_variants"].append({
                "ts": ts,
                "count": int(mv.group(1)),
                "variants": variants,
            })
            continue

        # ── Embedding block start ──────────────────────────────────────────
        if "STEP: QUERY -> EMBEDDING" in msg:
            flush_embedding()
            current_embedding = {"ts": ts}
            continue

        if current_embedding is not None:
            if (m2 := RE_EMBEDDING_QUERY.search(msg)):
                current_embedding["query"] = m2.group(1)
                continue
            if (m2 := RE_EMBEDDING_MODEL.search(msg)):
                current_embedding["model"] = m2.group(1).strip()
                continue
            if (m2 := RE_EMBEDDING_SHAPE.search(msg)):
                current_embedding["shape"] = int(m2.group(1))
                continue
            if (m2 := RE_EMBEDDING_VALS.search(msg)):
                try:
                    current_embedding["first8"] = [float(x) for x in m2.group(1).split(",")]
                except ValueError:
                    pass
                continue
            if (m2 := RE_EMBEDDING_NORM.search(msg)):
                current_embedding["l2norm"] = float(m2.group(1))
                flush_embedding()
                continue

        # ── Collection query params ────────────────────────────────────────
        if (m2 := RE_COLLECTION_PARAMS.search(msg)):
            session["collection_queries"].append({
                "ts": ts,
                "top_k_docs": int(m2.group(1)),
                "top_l_qa": int(m2.group(2)),
                "score_threshold": float(m2.group(3)),
            })
            continue

        # ── Collection timing ──────────────────────────────────────────────
        if (m2 := RE_COLLECTION_TIMING.search(msg)):
            session["collection_timings"].append({
                "ts": ts,
                "collection": m2.group(1),
                "seconds": float(m2.group(2)),
            })
            continue

        # ── Ranked results header ──────────────────────────────────────────
        if (m2 := RE_RANKED_HEADER.search(msg)):
            flush_ranked()
            current_ranked = {
                "collection": m2.group(2),
                "count": int(m2.group(1)),
                "items": [],
            }
            continue

        # ── Ranked result item ─────────────────────────────────────────────
        if current_ranked is not None:
            if (m2 := RE_RANKED_ITEM.search(msg)):
                current_ranked["items"].append({
                    "idx": int(m2.group(2)),
                    "score": float(m2.group(3)),
                    "source": m2.group(4).strip(),
                    "preview": None,
                })
                continue
            if (m2 := RE_RANKED_PREVIEW.search(msg)) and current_ranked["items"]:
                current_ranked["items"][-1]["preview"] = m2.group(1).strip()
                continue

        # ── [RETRIEVE] node summary ────────────────────────────────────────
        if (m2 := RE_RETRIEVE_NODE.search(msg)):
            flush_ranked()
            session["retrieve_nodes"].append({
                "ts": ts,
                "query": m2.group(1),
                "docs": int(m2.group(2)),
                "learned_qa": int(m2.group(3)),
            })
            continue

        # ── Validation verdict ─────────────────────────────────────────────
        if (m2 := RE_VALIDATE_VERDICT.search(msg)):
            flush_validation()
            current_validation = {
                "ts": ts,
                "verdict": m2.group(1),
                "relevant": int(m2.group(2)),
                "total": int(m2.group(3)),
                "reason": None,
                "chunks": [],
            }
            continue

        if current_validation is not None:
            if (m2 := RE_VALIDATE_REASON.search(msg)):
                current_validation["reason"] = m2.group(1).strip()
                continue
            if (m2 := RE_VALIDATE_CHUNK.search(msg)):
                current_validation["chunks"].append({
                    "passed": m2.group(1) == "✓",
                    "idx": int(m2.group(2)),
                    "note": m2.group(3).strip(),
                })
                continue

        # ── [VALIDATE_*] node summary ──────────────────────────────────────
        if (m2 := RE_VALIDATE_NODE.search(msg)):
            flush_validation()
            session["validate_nodes"].append({
                "ts": ts,
                "type": m2.group(1),
                "verdict": m2.group(2),
                "kept": int(m2.group(3)),
                "total": int(m2.group(4)),
                "query": m2.group(5),
            })
            continue

        # ── Encode timing ──────────────────────────────────────────────────
        if (m2 := RE_ENCODE_TIME.search(msg)):
            session["encode_times"].append({
                "ts": ts,
                "model": m2.group(1),
                "seconds": float(m2.group(2)),
            })
            continue

    flush_embedding()
    flush_ranked()
    flush_validation()

    return session


# ─── Pretty printer ───────────────────────────────────────────────────────────

def print_summary(s: dict) -> None:
    SEP = "─" * 70
    print(f"\n{SEP}")
    print(f"FILE : {s['file']}")
    print(SEP)

    if s["query_variants"]:
        for qv in s["query_variants"]:
            print(f"  Query variants ({qv['count']}) @ {qv['ts']}:")
            for v in qv["variants"]:
                print(f"    • {v}")

    if s["embedding_steps"]:
        print(f"\n  Embedding steps: {len(s['embedding_steps'])}")
        for e in s["embedding_steps"]:
            print(
                f"    [{e.get('ts','')}] query=\"{e.get('query','')}\" "
                f"shape={e.get('shape')} l2={e.get('l2norm')}"
            )

    if s["collection_queries"]:
        cq = s["collection_queries"][0]
        print(
            f"\n  Collection params: top_k={cq['top_k_docs']} "
            f"top_l={cq['top_l_qa']} threshold={cq['score_threshold']}"
        )

    if s["ranked_results"]:
        print(f"\n  Ranked result sets: {len(s['ranked_results'])}")
        for rr in s["ranked_results"]:
            top = rr["items"][0] if rr["items"] else None
            top_str = f"top score={top['score']}" if top else "empty"
            print(f"    [{rr['collection']}] {rr['count']} result(s), {top_str}")
            for item in rr["items"]:
                src = item["source"].split("\\")[-1]  # basename
                print(f"      [{item['idx']}] {item['score']:.4f}  {src}")
                if item["preview"]:
                    print(f"           {item['preview'][:80]}…")

    if s["retrieve_nodes"]:
        print(f"\n  RETRIEVE nodes: {len(s['retrieve_nodes'])}")
        for rn in s["retrieve_nodes"]:
            print(
                f"    [{rn['ts']}] query='{rn['query']}' "
                f"docs={rn['docs']} learned_qa={rn['learned_qa']}"
            )

    if s["validation_events"]:
        print(f"\n  Validation events: {len(s['validation_events'])}")
        for v in s["validation_events"]:
            pct = round(100 * v["relevant"] / v["total"]) if v["total"] else 0
            print(
                f"    [{v['ts']}] verdict={v['verdict']} "
                f"relevant={v['relevant']}/{v['total']} ({pct}%)"
            )
            if v["reason"]:
                print(f"      reason: {v['reason'][:100]}")
            passed  = sum(1 for c in v["chunks"] if c["passed"])
            failed  = sum(1 for c in v["chunks"] if not c["passed"])
            if v["chunks"]:
                print(f"      chunks: {passed} ✓  {failed} ✗")

    if s["validate_nodes"]:
        print(f"\n  VALIDATE nodes: {len(s['validate_nodes'])}")
        for vn in s["validate_nodes"]:
            print(
                f"    [{vn['ts']}] {vn['type']} verdict={vn['verdict']} "
                f"kept={vn['kept']}/{vn['total']} query='{vn['query']}'"
            )

    if s["encode_times"]:
        times = [e["seconds"] for e in s["encode_times"]]
        print(
            f"\n  Encode calls: {len(times)}  "
            f"avg={sum(times)/len(times):.3f}s  "
            f"total={sum(times):.3f}s"
        )


# ─── CLI ─────────────────────────────────────────────────────────────────────

def main() -> None:
    ap = argparse.ArgumentParser(
        description="Extract structured events from RAG pipeline debug logs.",
        formatter_class=argparse.RawDescriptionHelpFormatter,
        epilog=__doc__,
    )
    ap.add_argument(
        "log_dir",
        nargs="?",
        default="app_workflow/run_logs",
        help="Directory of .debug.log files (default: app_workflow/run_logs)",
    )
    ap.add_argument(
        "--file", "-f",
        help="Process a single log file",
    )
    ap.add_argument(
        "--filter",
        help="Only process files whose name contains this string (e.g. 20260623)",
    )
    ap.add_argument(
        "--output", "-o",
        choices=["json", "summary", "both"],
        default="summary",
        help="Output format (default: summary)",
    )
    ap.add_argument(
        "--combine",
        action="store_true",
        help="Write all sessions into a single all_sessions.extracted.json",
    )
    args = ap.parse_args()

    if args.file:
        log_files = [Path(args.file)]
    else:
        log_dir = Path(args.log_dir)
        if not log_dir.is_dir():
            ap.error(f"Directory not found: {log_dir}")
        log_files = sorted(log_dir.glob("*.debug.log"))
        if args.filter:
            log_files = [f for f in log_files if args.filter in f.name]

    if not log_files:
        print("No matching .debug.log files found.")
        return

    all_sessions = []

    for log_path in log_files:
        session = parse_log_file(log_path)
        all_sessions.append(session)

        if args.output in ("json", "both"):
            out = log_path.with_suffix(".extracted.json")
            out.write_text(
                json.dumps(session, indent=2, ensure_ascii=False), encoding="utf-8"
            )
            print(f"Written: {out}")

        if args.output in ("summary", "both"):
            print_summary(session)

    if args.combine and args.output in ("json", "both"):
        combined = Path(args.log_dir) / "all_sessions.extracted.json"
        combined.write_text(
            json.dumps(all_sessions, indent=2, ensure_ascii=False), encoding="utf-8"
        )
        print(f"\nCombined: {combined}")


if __name__ == "__main__":
    main()
