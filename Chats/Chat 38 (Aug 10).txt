It's distinguishing two independent questions that get asked about every agent call:

Vendor ("what does the work") — spec.backend, e.g. "claude" or "codex". This is set per node type in config.py:159-182 — e.g. "planner": AgentSpec(backend="codex", ...), "reviewer": AgentSpec(backend="claude", ...). It answers: which AI CLI actually generates the response for this node?

"maestro" → subprocess to maestro delegate, which then internally calls the vendor CLI
"stub" → fake in-process response, no subprocess at all (used in tests)
